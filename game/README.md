# game/ — English Quest 本体

ビルドなしの素の JavaScript（ES モジュール）。GitHub Pages でそのまま動く。

## 開き方（ローカル）

`fetch` で `data/` を読むので、`file://` では動かない。リポジトリの一番上でサーバーを立てて開く。

```
python3 -m http.server 8000
```

→ http://localhost:8000/game/

## 画面

| ファイル | 内容 |
|---|---|
| `index.html` | 入口 |
| `data.html` | データ確認（ファイルごとの行数・中身の表・絞り込み・`|` と `素材ID:個数` の分解表示） |
| `quiz.html` | 動作確認用：ルーンストーンを選んで4択を10問。日付をずらして復習の出方を確かめられる |
| `party.html` | パーティ：キャラメイク（仮）、4人の一覧、能力値、装備8枠の付けかえ（倉庫から）、スキルツリーと枠、共通ツリー、武器の熟練度 |
| `town.html` | 町：ギルド（クエスト・ランク）・宿屋・道具屋（バックパックを広げる）・武器防具屋（買う・売る）・神殿（復活）・倉庫。月末の会費 |
| `dungeon.html` | ダンジョン：行き先とルーンストーンを選ぶ → 階を進む → 戦闘（行動ごとに4択）→ 帰還ポイント・ボス → 町へ。全滅すると入る前に戻る |
| `save.html` | 動作確認用：自動保存・ダンジョンの途中からの再開・全滅で入る前に戻る、を仮の進み具合で試す |

## しくみ（`js/`）

| ファイル | 内容 |
|---|---|
| `csv.js` | CSV の読み込み（BOM の除去・引用符）、`|` 区切り、`素材ID:個数` の分解 |
| `data.js` | `data/` の CSV・JSON を読む（ファイルの一覧は `data/manifest.json`） |
| `lexicon.js` | ルーンストーンとルーン（単語）を使いやすい形にする |
| `srs.js` | 復習の時期の計算（FSRS を参考。設定は `data/srs.json`） |
| `storage.js` | 学習記録の保存（localStorage）。ゲームの進み具合とは別のキー。日ごとの合計も残す |
| `expr.js` | `balance.json` の式（`70 + g*30 + (Lv-1)*g*9` など）を計算する（eval は使わない） |
| `gamedata.js` | ジョブ・装備・適正などのデータを ID で引ける形にまとめて読む |
| `character.js` | キャラ：能力値・派生の値（クリティカル・回避）・装備8枠・適正・二刀流・レベル |
| `game-state.js` | はじめから始めるときの進み具合（4人のパーティ・倉庫） |
| `battle.js` | 戦闘：行動順・攻撃とスキル・属性・状態異常21種・道具・逃げる。乱数も状態に入れて保存するので、読み込み直しても結果は変わらない |
| `growth.js` | 成長：スキルツリーと AP、スキルの枠（持ち出し）、パッシブの補正、共通ツリー、ジョブを極めたボーナス、武器の熟練度、ジョブチェンジ |
| `town.js` | 暦と月末の会費・滞納、クエスト（掲示板・討伐/採集/ボス・報告）とランク、宿屋、店、神殿の復活、バックパックを広げる |
| `dungeon.js` | 遠征の進み方（階・戦闘・帰還ポイント・クリア・帰還）、戦闘の外の道具 |
| `loot.js` | 報酬（お金・素材・装備のレアリティとランダム効果・固有装備）とバックパック |
| `ui/battle-view.js` | 戦闘の画面（コマンド・対象・問題） |
| `encounter.js` | ダンジョンと階から出てくる敵を決める（ボス戦を含む） |
| `save.js` | ゲームの進み具合の自動保存（1つだけ・上書き）。ダンジョンに入る前の写し、戦闘の途中の保存、全滅で戻す |
| `picker.js` | 出題する単語を選ぶ（復習優先 → 間違えた単語 → 新しい単語 → 練習） |
| `quiz.js` | 4択の問題を作る（英→日・日→英、誤答の選び方） |
| `speech.js` | 英語の読み上げ（Web Speech API） |
