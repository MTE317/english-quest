# game/ — English Quest 本体

ビルドなしの素の JavaScript（ES モジュール）。GitHub Pages でそのまま動く。

## 開き方（ローカル）

`fetch` で `data/` を読むので、`file://` では動かない。リポジトリの一番上でサーバーを立てて開く。

```
python3 -m http.server 8000
```

→ http://localhost:8000/game/

## 6人編成（2026-11-23変更）

- 新規作成は6人。初期ジョブは `balance.json` の `new_game.party_jobs` を使い、キャラメイクで変更できる。
- 仲間・冒険中の概要は通常3列×2段、359px以下の仲間・遠征一覧は2列×3段。戦闘の6人一覧は3列×2段とし、出題中は開閉できる。
- 装備・能力・スキル・共通ツリーでは、6人の切替ボタンから同じ項目を続けて確認できる。
- 旧4人のセーブは町で2人を追加する。元のキャラの育成・装備・HP/MP・所持品・学習記録を保持し、追加キャラは既存メンバーの最低レベル、初期装備、AP0で加入する。再読込で重複加入しない。
- 旧セーブで遠征・挑戦が進行中なら、戦闘・未回答問題・全滅時の復元元を4人のまま保つ。帰還・全滅・挑戦終了で町に戻る際に6人へ移行する。
- 戦闘数値とシミュレーション結果の再調整は別工程。過去の比較用編成は人数を明示して4人のまま保持する。

## ルーンストーン（2026-11-23変更）

- 教材セットとして残し、刻印への装着・能力補正・共鳴・輝きによる戦闘ボーナスは廃止。
- 石碑の間の確認テストは任意。未予習・合格済み・不合格直後でも受験できる。20問・80%で合格し、学習記録に結果を残す。ゲームの能力・報酬・称号は付与しない。
- 学習履歴は項目IDごとに保持。教材の組み替えでは同じ項目のIDを維持する。旧覚醒記録も確認テストの過去の達成として引き継ぐ。
- 旧セーブの解放済み刻印枠は費用・素材を一度だけ返還し、遠征中の復元用の写しも移行する。支払い履歴のない刻み直し費用は推測しない。

## 音楽

町・ギルド・施設・ダンジョン・戦闘には、それぞれ3分のBGMがあります。
場面を往復すると各曲の続きから再開し、勝利ファンファーレは短い演出として毎回先頭から再生します。
曲の構成と再生成方法は [audio/README.md](audio/README.md) を参照してください。

## テスト

### 連続クエスト廃止後の配信互換

`data/quest_chains.csv` は旧ブラウザーのキャッシュに残ったデータローダー向けに、見出しだけの空ファイルとして残す。削除すると旧ローダーの必須読み込みが404となり、町の起動が止まる。現行のマニフェストと `GAME_FILES` には追加しない。連続クエストの内容・受注機能は復活させず、旧セーブの精算は `retired-quests.js` が行う。

`tests/retired-quests.test.js` で互換CSV、新規ゲーム、旧24依頼の再読込時の一度限りの精算、遠征中の復元元と全滅を確認する。

```
cd game
node --test tests/*.test.js  # recipes.test.js（171件・制作・戦闘の回帰テスト）を含む
```

## 追加の入口

- 町の神殿から、詠唱の間・JPでの転職・中級ジョブの解放を利用できる。
- 町の工房・調合、銀行・投資から、装備や道具の加工と施設の管理を行える。
- 工房は専用レシピ171件（武器114／防具27／マント10／アクセサリー20）を部位・★で絞り込める。専用装備には固定効果があり、素材・派生元・所持数を確認して制作できる。通常の汎用制作も切り替えて利用できる。
- ビルドの手引き画面は置かない。技能詳細には効果・段階・AP・前提を表示し、装備効果は条件を日本語で説明する。戦闘中には障壁の残りHPと通常攻撃からの技能準備を表示する。開発用の36案は `sim/build-catalog.json` で検証するが、ゲームからは読み込まない。
- メニューの「記録と設定」で、習熟の履歴・図鑑・称号・ダンジョンの出題方法を確認できる。

### 別管理のコンテンツ

闘技場の対戦データは、公開する環境の `data/` に次の CSV を置くと有効になる。
`rank` が1〜12なら同じ★の冒険者ランク、13ならSランクが必要。

| ファイル | 列 |
|---|---|
| `arena_tiers.csv` | `id,rank,name,first_medals,repeat_medals,title,gear_id,timed_title,direction_title` |
| `arena_battles.csv` | `id,tier_id,battle,enemies`（`battle` は1〜5、`enemies` は `monster_id:Lv|monster_id:Lv`） |
| `arena_shop.csv` | `id,gear_id,medals` |

上級ジョブ・追加ダンジョン・固有装備を公開する環境には、必要な行だけを
`data/extra_game_data.json` に入れる。値は既存 CSV と同じ列名をキーにした行の配列。
通常版では空のオブジェクト `{}` を配置している。追加コンテンツのない公開環境でも
存在しないURLを読まずに起動でき、追加コンテンツを使う環境はこのファイルの値を差し替える。
対応するキーは `jobsAdvanced`、`jobUnlocks`、`jobWeaponApt`、`jobArmorApt`、
`skills`、`jobMastery`、`monsters`、`materials`、`dungeons`、`dungeonFloors`、
`dropTables`、`uniques`。出題教材は `rune_stones.csv` と `lexicon.csv` で追加する。
