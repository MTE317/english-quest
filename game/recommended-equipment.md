# おすすめ装備の選択

所持品と対象キャラクターの現在装備だけを候補にする。仲間の装備は奪わない。

- ★・レアリティ順ではなく、適性・強化・熟練度・能力エンチャント・パッシブを含む装備後の実能力を比較する。
- ジョブの参照能力とセット済みスキルから物理／魔法の比重を決める。回復職は回復補正、護衛職は耐久を重視する。
- 使用可能なセット済み技能（パッシブ・奥義を含む）の武器条件を維持する。
- 主副武器とアクセサリー2枠はそれぞれペアで比較し、他の枠も改善がなくなるまで評価する。
- 同点は現在の装備を維持する。各枠の「おすすめ変更の対象外」は空欄にも設定でき、自動保存する。
- 全枠を決めてからまとめて交換し、最後にHP・MPの上限を適用する。装備交換途中でHP・MPを減らさない。

これは普段使いの評価であり、戦闘シミュレーションによる最大ダメージ保証ではない。通常攻撃と技能は半々の想定でサブ武器を評価する。回復効果、会心ダメージ、DEF無視、追撃、物理／魔法軽減、MP節約を補助評価する。敵の属性・種族・状態異常への対策や特殊効果の組み合わせは自動最適化せず、手動選択と固定枠で指定する。
