## 計測方法

[measure.mjs](measure.mjs) は sim/README.md に従い実ゲームのデータ読込み・職変更・習得/装着・装備可能判定・戦闘・出題可否・回復を使用する。#47の暫定モデル、#53のゲーム変更・fixture修正は使用しない。既存fixtureがmainで失敗するため専用の検証用編成を用意した。

固定5人は戦士・ナイト・白魔道士・盗賊・吟遊詩人。第6枠だけ黒魔道士/狩人/追加3職を交換する。Lv45、初期習得分と第3段までの現職技能、追加職は3技能全て。武器は各職の開始武器種、鎧は開始重量。正式装備からitemLv64以下の最高段、品質1.15・強化1・追加付与なし。通常の装備APIを通すが制作費を払う経済シミュレーションではない。固定5人の装備・技能は全条件で同一。共通ツリー・他職経由の追加技能・消耗品はなし。

春、正答率80%、seed 1217071 + 試行番号×7919、各条件40回。標準 sky_isles、深層 drowned_city は正式階層の通常戦とボス戦を連続実行し、戦間回復は実処理。精鋭・賞金首なし、戦間XP/AP・戦利品獲得なしでレベルと装備を固定。純粋な戦闘列の完走率であり、通常の遠征経済・報酬の計測ではない。

不利条件は正式敵のLv45単体戦。lava_golem は炎と火傷が無効。stone_statue は刺突耐性・魔法率0で、封印による魔法阻止の用途が乏しい。m08_006 はRES倍率1.45。正式データに封印完全無効・無属性耐性の敵はなく、後二者を完全無効ケースとは呼ばない。CのMP節約はこれらにも機能する。

`questions` は敗北を含む平均問数。`eligibleTargets` は正解行動時、既に火傷/封印がある対象への条件一致回数（命中確定前、追加ダメージの実発動回数ではない）。`statusApplied` は第6枠が新たに火傷/封印を付与した回数（既存状態の更新は除外）。`mpSaved` はCの正解行動分のMP節約量（不正解分を含めた総節約ではない）。`selected` は第6枠の現職技能の選択数。`mp` は終了時第6枠のMP割合。これらの制限を付けて役割の利用頻度を読む。特効の実ダメージ・軽減の対象/上限は別の制御回帰テストで確認した。

再現:

```sh
node --test game/tests/three-jobs.test.js
node game/verification/three-jobs/measure.mjs /tmp/three-jobs.json
```

前後比較は別のmain worktreeの同じ場所へmeasure.mjsだけをコピーし、`JOBS=black_mage,hunter node game/verification/three-jobs/measure.mjs /tmp/three-jobs-before.json`。技能が存在しなかった3職自体に実装前の勝率を捏造しない。前後の既存2職でエンジン変更の回帰を確認し、追加職は同じ固定5人の対照職と比較する。

## 費用と限界

新職はいずれも初期技能AP0＋パッシブ20＋奥義45＝65AP。転職JPはA250/B220/C200。A/Cは仕様表の既存素材各6個の奉納、Bは実際の封印使い討伐を含む依頼報告。検証用資源を供給し、解放・習得のAPIを通す。冒険何回で揃うか、ドロップ確率からの期待費用、依頼抽選待ち、宿・制作・強化の資金循環は未計測。既存職と習得技能数・AP投資の合計まで同一ではない。

40回では小差を断定できず、勝率100%でも一般の成功を保証しない。固定方策は状態特効の連携や奥義温存を最適化していない。四季・全行先・全装備・全持出し組合せ、ブラウザーの実時間、長期成長と経済は未検証。仕様決定が必要な再調整は行わない。

残30職について、素材奉納/討伐報告・既存技能・単純な条件付き特効で表せる職は同じ方法で独立検証できる。一方、予約/遅延の時点、専用印・資源・敵予告への応答・地図/素材/依頼追加が必要な職は依存機構と数値・解放IDの承認が必要。今回の3職の数値を残30職へ一律流用しない。
