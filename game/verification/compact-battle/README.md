# 戦闘情報の省スペース表示

基準main: 1ec762ec73d6bd7633cf89f513a113a6d98748c7（#70マージ後）。
既存アイコン・敵味方の配置・味方UI・戦闘/保存処理は維持。
敵名・カード数値・既知弱点・「図鑑」の文言を隠し、通常タップの詳細に残す。
MPプールがある敵は詳細に現在値/最大値を表示し、0も表示する。
王冠・エリート印は独立表示。警告と状態、対象指定中の選択は従来どおり。

最新3イベントを各1行、全体68pxの枠に固定。長文は省略し、タップで保持済み履歴を全文表示する。
保持数40件は既存ロジックのまま。履歴ダイアログは進行状態を変更しない。
出題中も同じ高さのプレビューを表示する。長文・イベント数で4択位置を変えない。
隠す帰還操作は戦闘中のページ上部の静的リンクのみ。

## 再現

リポジトリルートでHTTP配信し、PlaywrightとChromiumがある環境で実行する。

```sh
npm test --prefix game
python -m http.server 8774 --bind 127.0.0.1
BASE_URL=http://127.0.0.1:8774 node game/verification/compact-battle/browser-smoke.cjs
```

CHROMIUM_PATHでブラウザの場所、SCREENSHOT_DIRで画像の保存先（既存ディレクトリ）を指定可能。
新規ブラウザとメモリ内合成セッションのみを使う。

検証済み:
- 既定テスト339件成功（帰還地点・帰還の羽・全滅を含む）。
- Chromium、320/390 CSS px × 合成3/8体。味方6人、既存アイコン、タップ領域44px以上。
- 通常の敵詳細、未判明弱点の非公開、MP 0、ボス・エリート印。
- 戦闘中だけ上部リンク非表示、戦闘画面を離れると再表示。
- コマンド・対象選択・出題中の履歴開閉で戦闘状態が完全一致。
- 空/短文/長い開幕1件/40件の複数イベントでも4択位置・内容が同じ。
- 最新3件と履歴40件の全文、通常攻撃→対象→4択→正解精算、localStorage不変。

限界:
- 合成8体は通常の出現抽選ではない。実機・実セーブ・自然進行の全戦闘完走は未実施。
- 制限時間付き問題のタイマーは履歴表示中も既存どおり進む。
- 古い中止済みレイアウト、#69、添付スプライトの差分や素材は含めない。
