基準main: `15293c366c90e8e9850bdb5f269d998541da7113`。着手時のopen PRは#47（旧暫定計測）・#52（旧ローダー互換）で、どちらも取り込み・変更していない。[承認仕様](../../../docs/specs/basic-skill-levels.md)。

## 実装と互換性

- 基本8職123技能だけ前段習得条件を撤廃し、個別の習得APは維持。上位職の条件・共通ツリー・奥義の回数制限は変更しない。
- 正式skills.csvの17技能にLv2/Lv3の追加費用10/20 APと承認された威力/支援量・MPを記録。既存行のID、Lv1効果、習得AP、枠、状態率、奥義属性は全件一致。BOM維持。
- 習得Lvと使用Lvはキャラ別の任意マップ。未指定はLv1、強化しても使用Lvは変わらない。所属職APを使い、転職・持出しでも記録を保持する。
- 保存外枠version 1・既得AP/装着/masteredJobsは維持。全強化はマスター条件に加えない。実ユーザーのセーブは使用していない。
- 画面・戦闘候補・MP計算・実行は同じ使用Lvを参照する。CSVの元定義を書き換えないので他キャラへ波及しない。更新されたJSの依存元とHTMLのバージョンも更新し、古い成長/戦闘モジュールとの混在を防ぐ。

## 本体JSの比較条件

`sim/README.md`に従い、正式CSVと本体battle/growth/character/encounter/dungeonを使う。#47の暫定モデルは使わない。

- 正答率80%、春、seed `1217071 + i * 7919`、各24試行。
- 固定5人: 戦士・ナイト・白魔道士・狩人・吟遊詩人。6枠目だけ基本8職を交換。
- 苔むした洞窟（★1標準）: Lv8、装備itemLv10以下。沈んだ神殿（★4標準）・沈黙の大回廊（★4深層）: Lv30、itemLv36以下。
- 装備は正式定義の最高段、職の開始武器/防具種、品質1.15・強化1、追加付与なし。道具・精鋭なし。固定5人は各30 APの同じ技能を装備。
- 第6枠baselineは初期技能のみ（30 AP未使用の対照）、wideは10 APパッシブ＋20 AP技能、level3は初期主力1技を追加30 APでLv3、ultimateは前提撤廃後の奥義を30 APで直接習得。同じ比較枠内では同レベル・装備・seed・正答率。baselineだけは支出0であり「同額投資」の比較に含めない。
- wideの購入内容はmeasure.mjsに職別IDで固定。旧mainでも前提を満たして取得できる。8職の主力1技の戦闘列比較であり、全17技すべての組合せ比較ではない。
- 正式階層/ボス/取り巻き/戦間回復を使用。戦間の経験値・AP・素材・戦利品は加えず、育成を固定。選択方策は既存chooseActionを共通使用し、勝率を合わせる補正はしない。
- 勝率はこの戦闘列の完走率。問数は敗北も含む1試行平均、normal/bossは到達戦闘の平均。endMpは第6枠の終了時MP割合、mpSpentは選択された技能の支払予定MP、skillsは第6枠の技能選択回数。発動後のMP回収はendMpに反映する。

## 再現

```sh
cd game && npm test
# リポジトリルートから
RUNS=24 node game/verification/basic-skill-levels/measure.mjs /tmp/basic-levels-results.json
```

変更前は基準mainの独立worktreeへmeasure.mjsのみコピーし、次でbaseline/wideを同条件計測する。未実装だった強化や前提解除を旧mainへ仮実装しない。

```sh
MODES=baseline,wide RUNS=24 node game/verification/basic-skill-levels/measure.mjs /tmp/basic-before.json
```

画面確認は別ターミナルで `python -m http.server 8765 --bind 127.0.0.1`、PlaywrightとChromiumがある環境で `node game/verification/basic-skill-levels/browser-smoke.cjs`。必要ならCHROMIUM_PATH/BASE_URLを指定。追加のブラウザ依存は通常CIへ要求しない。

## 限界と判断

Lv・AP・装備は合成fixtureで供給しており、新規プレイからAPや教材・解放を獲得する経済/進行計測ではない。既存の教材量による昇格・進行上限を通過できる証拠にはならない。24 seedでは小さな勝率差を断定しない。全17技能の最大化・全員同技能・全装備・全行先・全正答率の最適化は未検証。

状態率・奥義回数・個別価格は承認どおり据え置き。問題があっても別のルールやバランス再調整を無断採用しない。マージ/デプロイは本作業の対象外。
