- 固定5人: 戦士・ナイト・白魔道士・狩人・吟遊詩人。6枠目だけ基本8職を交換。
- 苔むした洞窟（★1標準）: Lv8、装備itemLv10以下。沈んだ神殿（★4標準）・沈黙の大回廊（★4深層）: Lv30、itemLv36以下。

- 第6枠baselineは初期技能のみ（30 AP未使用の対照）、wideは10 APパッシブ＋20 AP技能、level3は初期主力1技を追加30 APでLv3、ultimateは前提撤廃後の奥義を30 APで直接習得。同じ比較枠内では同レベル・装備・seed・正答率。baselineだけは支出0であり「同額投資」の比較に含めない。

## 限界と判断

Lv・AP・装備は合成fixtureで供給しており、新規プレイからAPや教材・解放を獲得する経済/進行計測ではない。既存の教材量による昇格・進行上限を通過できる証拠にはならない。24 seedでは小さな勝率差を断定しない。全17技能の最大化・全員同技能・全装備・全行先・全正答率の最適化は未検証。

状態率・奥義回数・個別価格は承認どおり据え置き。問題があっても別のルールやバランス再調整を無断採用しない。マージ/デプロイは本作業の対象外。

## 使用Lvを下げた状態の低MP回帰

追加回帰で習得Lv3から使用Lv1へ変更し、Lv1コストより多くLv3コストより少ないMPで行動候補が有効、実ダメージはLv1、支払いもLv1であることを確認。ブラウザでも通常createBattleViewのスキル選択→出題→正答ボタン→本体resolvePendingを通し、習得Lv3/使用Lv1の炎弾がMP5で「Lv1・MP4」と表示され、実行後MP1になり習得Lv3は保持された。画面確認は新しい隔離contextと合成セーブで行い、実セーブを操作していない。
