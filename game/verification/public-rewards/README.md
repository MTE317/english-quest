# 公開6地域の固定EXP/AP

基準: main `2e319cca83864c2d1a15ac948c3be213e7945160`。承認された77種の値を `data/monsters.csv` の `base_exp`, `base_ap` に設定。その他の列・1024体のIDは変更しない。対象地域は `balance.rewards.fixed_monster_dungeons` に独立して保持する。

## 計算と互換性

- 公開6地域の通常遠征では、敵IDごとの基礎EXP/APを合算する。敵Lvから基礎値を再計算しない。ボス・賞金首の基礎EXPには既に5倍相当が含まれる。
- EXPは各敵の既存冠倍率→既存味方Lv差補正→合算→装備/パッシブ補正→丸め、さらに既存の出題元倍率を適用する。APは各敵の基礎AP＋冠がある敵1体につき1。APへのLv差補正はない。
- 死亡/石化の配布判定、訓練、闘技場、初期AP、共通残高、負け/逃走、全滅時の過去の勝利分保持は変更しない。
- 地域指定なし・対象外地域・旧育成探索は従来報酬。対象地域でも未設定の敵が混じる旧遠征（例:旧森ボス）は**その戦闘全体**で従来計算に戻す。一律APだった旧規則に未知敵だけの仮APは作らない。
- セーブ形式/ID/既存残高を変更しない。保存済み戦闘も地域と現在のマスターを参照して決済する。既に受領したXP/APは再計算しない。既存の `endBattle` による保存と戦闘消去を利用し、再読込で再払いしない。
- 図鑑の能力・経験値欄は討伐20体（ボス4体）の既存解放条件のまま、設定済みIDは「公開ダンジョンの基礎経験値」を表示する。記録時Lvや未公開地域の報酬額とは明確に区別。未設定IDの既存の目安表示は維持。
- JS依存とHTML入口のバージョンを更新。CSV取得は既存の `cache: no-cache`。

## 再現

```sh
npm --prefix game test
node game/verification/public-rewards/measure.mjs
python -m http.server 8773 --bind 127.0.0.1
# 別ターミナル。Playwright と Chromium が必要
NODE_PATH=/opt/codex/cua_node/lib/node_modules node game/verification/public-rewards/browser-smoke.cjs
```

`measure.mjs` は本体の GameSession / startRun / startNextBattle / afterBattle と正式データを使用。旧比較は同一データの対象地域設定だけを無効にして従来式へ戻す。出現・性能・装備には変更を加えない。旧ローカルAP試作は使用していない。

`results.json` の `encounters` は4季節×128 seed/地域（計3072遠征）。seed=172903+n×7919。実際の遠征抽選・冠上限・賞金首・ドロップ乱数を通すが、戦闘を勝利に置換し、各戦の味方Lv1で過剰レベル補正を避けた**報酬比較**。勝率や難易度の実戦検証ではない。

`progression` は4季節×32 seed/条件。原→森→洞窟、次地域のseedは+101。初期20AP/10000Gから既存fixtureの購入・習得APIで支度し、ドロップ装備や依頼/借入は使わず、原/森後は宿泊。`fought:false` はLv差込み全勝を仮定、`fought:true` は実戦エンジンで正答率65%/80%を抽選。使用技能は初期支度時に固定し、獲得APの追加投資はしない。EXP/AP集計は先頭メンバー1人の当該遠征での取得、raw `balances` と `lv` は6人分。戦闘不能者は報酬がなく、全員が同時にLv4になる保証ではない。問数はシミュレーションの値で、実測プレイ時間ではない。

## 結果

全勝・Lv差なしの平均（1人/遠征）:

| 地域 | EXP 旧→新 | AP 旧→新 |
|---|---:|---:|
| 風渡りの原 | 64 → 66 | 6 → 6 |
| 木漏れ日の森 | 97 → 93 | 6 → 7 |
| 苔むした洞窟 | 222 → 216.5 | 10 → 11 |
| 小鬼の石切り場 | 202.125 → 201.926 | 8.203 → 10.424 |
| 崩れた砦 | 390.633 → 393.711 | 8.203 → 14.791 |
| 霧の湿原 | 427.844 → 429.887 | 8.203 → 15.381 |

承認時の後半3地域の目標平均とはseed・抽選の標本差がある（最大EXP差約0.6）。承認値を目標平均に合わせて再調整していない。

Lv差込み全勝仮定では新旧とも原Lv2→森Lv3→洞窟Lv4（全6人）。新APは各6/7/11、計24（旧22）。実戦の各正答率・各地域は128/128踏破。平均問数は新旧同じ: 65%で44.91/59.94/82.42、80%で39.78/52.72/72.36。洞窟で脱落したメンバーはLv3のままの場合がある。先頭メンバーの65%洞窟報酬は旧215.125EXP/9.75AP→新209.625EXP/10.75AP、80%は旧222/10→新216.5/11。

これは初期固定方策と支度に限る結果。全編成の勝率、AP増加による長期の技能取得速度、未公開地域の実戦バランスは検証していない。後半3地域は出現と報酬の全勝サンプルであり実戦攻略は今回未実施。
