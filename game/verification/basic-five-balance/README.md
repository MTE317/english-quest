# 基本8職と公開5ダンジョンのバランス監査

基準main: 0dcf37c（#72マージ後）。本体JS・正式データを使用。
**数値変更は未採用。** 役割・相性を越えて優遇/不遇を断定できない差を埋めるための強化・弱体化は行わない。
実測表と判断は REPORT.md、入力と試行別結果は results.json。

## 再現

リポジトリルートから実行する。

    RUNS=24 node game/verification/basic-five-balance/measure.mjs /tmp/basic-five.json
    node game/verification/basic-five-balance/roles.mjs /tmp/roles.json
    node game/verification/basic-five-balance/weapons.mjs /tmp/weapons.json
    node game/verification/basic-five-balance/equipment.mjs /tmp/equipment.json
    npm test --prefix game

DUNGEONS=mossy_cave で行先を絞れる。ACCURACY=0.8が既定。
各行先を別プロセスで実行してもseed列・結果は同一。
results.jsonは5行先の結果を統合し、fixtureと全試行を保持する。
遠征seed 1217071 + i×7919。行動が変われば同じseedでも後続の個別イベントは変わる。
データ/エンジンのfingerprintと完了時一致を記録する。

## 対象・条件

8職は戦士、ナイト、黒魔道士、白魔道士、盗賊、武闘家、狩人、吟遊詩人。
5か所はworld-map.jsの洞窟・森・採石場・砦・湿原。他の55行先は対象外。
固定5人（戦士・ナイト・黒魔道士・白魔道士・吟遊詩人）+第6枠を8職で交換。
全員同レベル、同じ入手経路・装備Lv・品質・強化。Spring・正答率80%、各24seed。
通常/階別/ボス、踏破、問数、回復品、残HP/MP、主役の直接ダメージ・回復・技能MP・支援発動を保存。
エリート・賞金首優遇は除外し、正式な季節置換とボス随伴はそのまま使う。

| 条件 | ★1（洞窟/森/採石場） | ★2（砦/湿原） |
|---|---|---|
| 初攻略準備 | Lv1、AP0、初期装備Lv3、品質1 | Lv6、AP30、R02店売り装備Lv13、品質1 |
| 周回・店装備 | Lv5、AP30、既存装備Lv3、品質1 | Lv10、AP30、店売りLv13、品質1 |
| 周回・通常制作 | Lv5、AP30、通常制作Lv8、品質1.15 | Lv10、AP30、通常制作Lv18、品質1.15 |

強化0、付与なし、自職のみ、技能Lv1。奥義・高AP構成・持出し最適化は含まない。
通常制作はcraft/equip APIを通し、24部位で通常素材96個を使う。
★1ではゴブリン素材、★2では砦の山賊素材。周回制作は既に収集した段階であり初攻略条件にしない。
素材収集回数・所持金の推移を再現したものではない。

★2初攻略は必要な前段階クリア・R02昇格・購入資金を満たした進度スナップショット。
対象ダンジョン自身の報酬・素材を初攻略装備の条件に使わない。
店売りはgearShopStock/buyGear、消耗品はbuyItemで品揃え/価格を確認する。
組立用資金を別枠で供給して購入額を記録。初期支度金だけで全装備を買えるとは主張しない。
周回・店装備の★1は初期装備と同一なので実際は再購入不要。
setupGoldはfixtureの購入総額（既存品の再購入も含む）で、最小追加費用ではない。
工房ランク2の投資300G/施設は組立費に含まれない。

持込は回復薬3・魔力の水2・気付け薬1・毒消し2。
戦闘間の使用、自然回復、勝利XPによるレベル上昇は本体API。
APは出発前予算で途中習得なし。戦利品を装備/使用する処理は入れず、全滅時は打切る。

## 職と装備を勝率以外でも確認する

roles.mjs: Lv6・初期装備・128seed、ゴブリン/砦/湿原ボスで代表技と通常攻撃を比較。
傷ついた味方と敵反撃1回を準備し、回復・かばう・防御支援も見る。
盗みと通常素材ドロップは別計測し、全体勝率のランキングに混ぜない。

weapons.mjs: Lv10・32seed、同じLv18/品質1.15の通常制作武器対、5地域の素材で作れる専用武器。
制作・派生元・装備APIを使用。防具は初期装備固定。全遠征ではなく行動/反撃プローブ。
equipment.jsonは春の出現プールとボスから素材の出所・派生元を照合。
レア素材の即時入手や最適構成を保証しない。

## 限界と調整判断

- 固定5人に支援役がいる。第6枠の支援職の問数増を、その職自体の不遇と解釈しない。
- 既存chooseActionは相性をデータから参照し、完全初見の人間の判断ではない。
  盗む/見極め/MP譲渡などを通常方策が十分使わないため役割プローブを併記する。
- damageは主役の行動直後のHP差。後続DOT・反撃・バフ増分を全て主役に帰属させない。
- 24試行は微差の確定には不足。100%でも真の成功率100%を保証しない。
- 正答率65/95%、四季、エリート/賞金首、完全な経済/教材進行、技能Lv2/3、全装備・付与は未網羅。
- sim/README.mdの標準70%等は旧4人条件を含む。今回の6人条件へ機械的に当てはめない。
- 数値を変えていないため「変更後の改善」は未実施/非該当。既存数値の基準計測を保存する。
