# 訓練XPの必要経験値曲線への追従

基準 main: `0dcf37c757d776b612ed86b731c8d223c1814f92`。基本職/5地域監査PRとは独立。

## 採用式

各キャラ・報酬対象の1問ごとに、丸め前XPを次の式にする。

```
N(L) = round(25 * L^1.5)                 // character.xpToNext、正式データ
old = (Number(game.xpPerQuestion) || 5) * 0.10
floor = Lv上限未満 ? N(本人の現在Lv) * 0.001 : 0           // balance.training.xp_min_level_fraction
XP = max(old, floor) * (期限到来かつ正答 ? 1.20 : 1)
```

従来の小数繰越に足して整数分だけ既存gainXpへ渡す。追加セーブ項目なし。Lv99は下限補正を追加せず、既存gainXpがXPを破棄し、Lv/蓄積XPを増やさない。既存どおり結果画面の合計XPは上限による破棄前の額なので、Lv99の表示XPを実成長とは解釈しない。

初期参照値5ではLv1〜7の0.5XP/問を維持し、Lv8から下限が効く。下限が支配する場合、基礎報酬1,000問でおよそ次Lv分、5/10/15問で0.5/1/1.5%。期限正答は1.2倍。Lvを単純に掛けず、序盤の2%/問を全Lvに維持する50問/Lvの急速成長にもしていない。高Lvほど必要量が増える実際の曲線に、控えめな進捗下限を置く数値変更。

従来参照値は「直近の安全帰還で全員が得た合計XP÷遠征の問題数」。1人の平均ではない。その10%を各人に配るため、全員生存・同量XPなら、従来訓練は既に平均1人戦闘XP/問の約60%。この参照にさらにレベル倍率を掛けない。参照値が高ければ従来額をそのまま維持し、低レベルの仲間にも従来どおり同額が入る。今回その別問題を修正しない。

## 対象と維持する挙動

- 単語・熟語、通常の瞬間英作文、チャンク集中、復習はすべてtraining-runnerの同じ報酬経路。復習の単語/英文/両方、期限/苦手でも同じ。1項目1日1回はkind+IDで共通。失敗でも基礎報酬が入る既存挙動を維持し、正答率は期限ボーナスのみに作用する。
- 受給者はパーティ全員（戦闘不能者も含む）。各人のLvで下限を計算。現職AP、他職APの繰越、金・素材・日数は変更しない。
- 各解答時のGameSession.updateで保存、途中終了でも既に獲得した分は残る。セッション完了報酬や周回ボーナスを追加しない。
- 予習閲覧、確認試験、昇格試験、訓練外の英作文記録にXP経路を追加しない。これらは今回のXP対象外。
- `docs/game-overview.md` の「1人」「今の★で減衰」およびdata内の旧鍛錬説明は現行training.jsと一致していない。今回の基準は実装済みの全員報酬・減衰なし。旧説明を根拠に新しいランク上限や受給者変更は導入しない。

## 再現

Node.js、追加パッケージ不要。リポジトリのルートで:

```
node game/verification/training-xp/measure.mjs /tmp/training-xp-results.json
npm --prefix game test
```

mainの旧training.jsを固定SHAからgit showで読み、同じ本体character.jsと正式データでbeforeを実行する。afterは変更後training.jsを直接実行。シミュレーション専用の報酬再実装ではない。基準コミットを含むgit履歴が必要。fingerprintとtrainingSha256・harnessSha256を結果に記録する。

訓練: Lv1/5/10/25/50/75/98/99 × 参照XP5/30 × 4モード × 期限なし/あり = 128条件をbefore/afterで比較。5問×20実日、単語/通常英作文は実教材100ID、チャンク/復習は5IDを日を替えて反復し、各条件100問・80正答（5問中1誤答）。ゲーム内日数は進めない。報酬経路の検証であり、SRSの期限や新規学習ピッカーが毎日同じ5IDを選ぶとの主張ではない。モード別のword/phrase IDを使用し、画面の操作時間・音声・英作文の自己評価精度はモデル化しない。複数Lv混在と保存・再開は回帰テストで検証。

戦闘: 同じ6基本職、春、洞窟/砦の1F通常・最終ボス、8Lv、16seedずつ=512戦。seed1217071+i*7919、正答率80%。Lv1/5は初期装備、Lv10以降はR02店のilvl13・品質1装備。取得済み初期技のみ。各戦満タンで独立実行、本体の遭遇/行動/ダメージ/戦闘報酬を利用し、勝利時だけXPを集計。Lv1砦などは未育成ストレス条件であり、推奨進行ではない。単戦なので安全帰還・遠征全体の消耗や成長は比較しない。戦闘の勝敗・問題数は訓練式で変化しない。訓練との比較は1問・1人あたりに正規化。戦闘の集計から得る訓練参照値は比較用推定で、実際の最後の帰還セーブではない。

適正Lv報酬プローブは洞窟敵2体のLvだけを合わせてbattleRewardsを呼ぶ単価比較。戦闘時間・勝率を測る実戦ではなく、高Lv地域が現在入場可能という意味でもない。公開5地域を越える高Lvコンテンツとの実戦比較は未実施。

## 注意点

公開地域で敵より5Lv高いと戦闘XPは0。既存訓練にはその減衰がなく、今回の下限で高Lv時の差は拡大する。冒険より常に遅いという保証はしない。冒険はAP・素材・装備・解放でも進むが、高LvのXP目的では訓練が優位になる。訓練にも地域/ランク上限を加える、既存参照を1人平均に変える、Lv99の表示XPを0にするのは別の仕様判断として未変更。自動マージせず、この制約を含めてレビューする。
