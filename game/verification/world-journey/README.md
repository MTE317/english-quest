## 自動テスト

`node --test game/tests/*.test.js`

778件成功、失敗0。新規 `world-journey.test.js` では以下を確認：

- 13地点、39出口、各3戦、4入口以外からの出発拒否。
- A→B→D→Gの12戦、E→F→KとH→I→Jの9戦、石到着後の帰還。
- 再挑戦、HP・MP・持ち物・教材引き継ぎ、出口の重複操作拒否。
- 春の閉鎖と恒久ワープ、複数条件の順序非依存。
- 羽での帰還、全遠征の戦利品喪失と全滅後の地図保持、再読み込み。
- イベントなし、敵数・種類の抽選、最終戦の逃走では踏破しない。
- 煙玉、旧セーブと依頼の移行、昇格素材経路。

## ブラウザ

`node scripts/verify-world-journey.cjs`

PlaywrightとChromeを使用。必要なら `CHROME_PATH` と `NODE_PATH` を指定する。ローカルファイルをPlaywrightのルーティングから配信するためHTTPサーバーは不要。ユーザーのセーブは使わない。

幅320px・390px・1000pxで入口4択、出口3択、地図、Bへの移動、再読み込み、石2解放と帰還、解放後の石選択を確認。ページ全体の横はみ出し・JavaScriptエラーなし。[結果JSON](browser-results.json)。

ブラウザ検証は高レベルの専用データを作り、戦闘結果を勝利に固定して実際の結果処理と画面遷移を検証する。英語回答を含む全戦闘の手動攻略や、初期パーティーでの9〜12戦の難度・経済バランスを検証したものではない。
