# 戦場の見出し・透明カード・表示順

基準main: fb63c69dca32738f0981ac70205adec9fba238b2（#71）。
DOMは戦場（場所名と階、敵）→最新3行ログ→操作/英語4択→味方切替・味方。
通常の敵カード背景と戦場外枠を外し、既存の風景を戦場全体に残す。
場所の行は通常フローなので長い名前が折り返しても敵やバーには重ならない。
ラウンド表示だけを除去し、戦闘中だけ外側ページ見出しを隠す。
闘技場では既存のrun.labelと対戦番号（battlesDone + 1）を使う。

ログは.9rem、各24px × 3行、枠86px。長文はプレビューだけ省略し履歴に全文を残す。
#71の敵詳細・MP0・王冠/エリート印・警告/状態、履歴40件と戦闘状態保持を継承する。
味方UIは下段へ移すのみ。出題時の既存の開閉方式と正解・不正解の表示を維持。

## 再現
PlaywrightとChromiumを用意し、リポジトリルートで:
```sh
npm test --prefix game
python -m http.server 8775 --bind 127.0.0.1
BASE_URL=http://127.0.0.1:8775 node game/verification/battle-field/browser-smoke.cjs
```
CHROMIUM_PATH、SCREENSHOT_DIR（既存ディレクトリ）を指定可能。
新規ブラウザとメモリ内合成セッションのみ使用する。

- 既定テスト339件成功。正規の帰還地点・帰還道具の既存テストも成功。
- 320/390 CSS px × 合成3/8体、味方6人。森の背景、カード透明、DOM順、44px以上の敵タップ領域。
- 長い場所名、3行ログの空/短文/長文1件/40件、履歴開閉でも対象・問題と4択位置を保持。
- 敵詳細・既知情報のみ公開・MP0・印、通常攻撃→対象→4択→正解。
- 320/390pxで回復薬/気付け薬の味方選択→正解→HP回復/蘇生・消費1個。
- 闘技場ラベル/対戦番号、戦闘外ヘッダー再表示、通常localStorage不変。

合成編成は自然の出現抽選ではない。実機、全自然進行、音声の実聴は未検証。
データ・戦闘ルール・保存形式・背景素材は変更しない。中止済みの案や添付絵は使用しない。
