## 入力と比較条件

- 同梱 `inputs/fort-{season}.json` は検証③〜⑤の board-safe 方策を再実行した**合成セーブ**。新規から依頼・回復・AP再投資・限定強化を経て、各開始季節の正答率80%、seed系列0で初めて砦を突破した4状態。ユーザーの保存データではない。
- 戦士/騎士/黒魔道士/白魔道士/盗賊/吟遊詩人の6人。Lv9〜10、残高44,340〜53,150G、累積1,330〜1,690P。初回峡谷そのものにD+を要求しない。**入力は成功者選抜済みで、新規開始全員の到達率ではない。**
- 武器・防具は実際に得た★1/2、武器の一部+1。`staff_t4` はID末尾4だが実データ上★2。制作・再抽選なし。峡谷で拾った★3装備も、再挑戦の装着候補から除外する。
- 四季の遭遇 × 正答率65/80/95% × 4戦闘seed × 4入力。正答率ごと各64開始。各セルでLv10/12/15候補とLv15/17/19対照を同じseed・装備・方策で比較する。対照にも新報酬・単独ボスを使い、**入口レベルの効果を分離**する。旧版全体との直接比較ではない。
- calendarだけを季節の初日に合わせ、遠征による日数経過は実処理。候補24種の網羅は別の単体テスト。実サンプルが24種全てを引く保証はない。
- 素材試験は1階勝利後、羽で帰還。持ち帰りが無ければ最大3遠征。各回、実資金で神殿/宿/既定消耗品補充を行う。全滅・費用不足は成功扱いにしない。EXP/APは実付与を保持し、今回の追加AP購入はしない。
- 全踏破試験は同じ入力から別に3階を目指す。素材試験との成長の使い回しなし。共通の `chooseAction` は最適戦術ではない。全滅の問数を勝利問数へ混ぜない。秒や実プレイ時間へ換算しない。
- 湿原のみを先に突破する追加経路は、D到達時点の四季×80/95%の8開始で0/8踏破だった。主比較に湿原単独成功者を捏造・流用していない。湿原OR条件は単体テストとブラウザの合成機能試験で確認し、**湿原単独の自然進行性能は未確認**。

G差分は入力の砦戦後から神殿/宿/道具補充/必要な羽購入/遠征費/獲得金を合算。勝利後の全回復費用は含まない。4入力の高い残高を前提にしており、無資金プレイヤーでも同様に回せるという意味ではない。消耗品の既定補充量を固定したため、消費が少なくても初回準備費は同じになり得る。

候補の1階勝利で、先頭メンバーへの実付与平均は EXP82.25 / AP4.50（各正答率共通）。他メンバーは脱落時の既存配布判定に従う。勝利だけでなく全失敗の育成/所持品状態も生ログに残している。`results.json` の `itemsUsed` は**戦闘内**消費の全試行合計で、戦闘前の回復・羽は別。Lv10の65%条件はポーション69・エーテル2・蘇生塩3、対照Lv15は177・24・36だった。

候補の全踏破試験は各正答率 **0/64**。65%は2階48/3階16、80%は2階22/3階42、95%は2階18/3階46で敗北した。単独ボスへ到達しても現方策では未勝利。対照も0/64。**D+素材は初階で取得できるが、砦初踏破直後のこの編成で峡谷全踏破できるとは言えない。** 2階・ボスの追加弱体化、特定対策の必須化、昇級タイミング変更は行っていない。全踏破も同時に容易にする意図なら別途相談が必要。

今回の候補素材持帰り192/192は4入力×4遭遇季節×4seed×3正答率の有限結果。入力が成功者に偏り、seed/編成を共有するので独立な192人の勝率推定ではない。既存短剣等の素材補正も効く。基礎70%や条件付き91%を書き換える根拠にはしない。
