## 6人編成の比較

sim/README.mdに沿い本体JS・正式データ・同じseedを使用。Lv45、装備itemLv54以下の最高段、品質1.15、強化1、追加付与なし、道具なし、春、正答率80%。固定5人は戦士・ナイト・黒魔道士・白魔道士・盗賊、第6枠だけ銃士/Dを交換。3段までの現職技能（Dは全4技能）、AP・素材・装備は検証用に供給し、Dの解放・転職・習得・装備は本体APIを通す。装備を工房で購入する費用・素材採集の長期経済は再現しない。

標準sand_tombと深層millennium_rootを各40 seed、seed 1217071+i×7919。正式階層・ボス＋取り巻き・実戦間回復を使用し、精鋭/賞金首なし、戦間のXP/AP/報酬/戦利品なしで育成を固定する。完走はこの戦闘列の完走率で、経済を含めた通常遠征の成功率ではない。

通常方策はsim/balance.mjsのchooseActionを使う。Dについては別に石化優先方策（石化可能な敵が複数なら奥義、次に通常弾、石化不能だけなら穿岩弾）も計測する。石化技を選ばない方策だけで安全と結論しない。将来の乱数は参照しない。

パッシブなし、穿岩弾だけの対照も用意する。混合編成は固定4人＋銃士2人を対照に固定4人＋D2人で比較し、主たる1枠比較とは分ける。重複装着はセーブ正規化後に同じ12 seedの戦闘結果が全て一致することを別途確認する。

`normal.questions`/`boss.questions`は到達した戦闘の敗北を含む平均問数。bossは取り巻き込みの戦闘区分で、そこで取り巻きが石化してもボス石化とは数えない。`bossPetrified`がボス本体の件数。`stoneFinishes`は敵のHPを残して石化で勝利条件を満たした戦闘数。`pierceDamage`はその戦闘区分で穿岩弾が与えた全実ダメージ（取り巻きも含む）。`mp`は第6枠の終了時MP割合。

この確定部分の試験範囲では、既存編成の回帰や石化の大幅短縮、ボス免疫破り、重複装着/味方人数による率の乗算は観測しなかった。承認数値の再調整は行わない。仕様確定後もゲームコード・正式データ・計測ハーネスに変更がないため、上記の計測結果は同じ挙動に対応する。今回の文書更新で長期シミュレーションは再実行していない。


## 仕様確定時の回帰検証と進行上の限界

追加回帰テストは同じ256 seedで命中付き銃技のパッシブ有無を比較し、石化が増えるケースを確認する。一方、既存の状態専用「石化弾」は銃装備・パッシブ有無でseedごとの成否が完全一致し、ダメージを与えず、対象の回避率を100%にしても従来の状態判定を行うことを確認する。基礎率35%の正式データも検証する。

新規プレイには★4教材不足による既存の進行上限がある。本計測は検証用にレベル・素材・AP・装備を供給した戦闘比較であり、その上限を通常プレイで通過したことや、Dを新規プレイから取得できることを示さない。この問題の修正は本PRに含めない。
