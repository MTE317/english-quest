# スキル画面の32pxアイコン

添付の素案を基にした透過PNG。全素材・表示サイズとも32×32px。スキルごとの画像は増やさず、次の26種を共用する。

- 物理攻撃：斬・打・突、および火・氷・風・地・雷・水・光・闇・無の12種。元素属性の物理技も剣の形を保ち、魔法陣と区別する。
- 魔法攻撃：火・氷・風・地・雷・水・光・闇・無の9種。同じ魔法陣を色と中央の属性モチーフで区別する。
- 回復・補助・妨害・パッシブ・奥義：各1種。パッシブと奥義は主効果や属性を問わず、それぞれ本・王冠の共通画像。

`game/js/ui/skill-icons.js` が技能の分類と画像を共通管理。習得・強化、共通パッシブ、装備・取り外しの一覧と選択詳細へ適用する。

武器依存技は装備武器の攻撃種別と属性を参照し、技能の固定属性を優先。対応外の武器または未装備の場合は使用条件に含まれる武器で予告する。複合属性は先頭属性の画像とし、画像のタイトルに全属性を記載する。相手に有利な属性を選ぶ技もタイトルで区別する。攻撃に状態異常が付随する場合は攻撃アイコンを使う。

`game/tests/skill-icons.test.js` で26素材の形式・寸法、分類、武器依存、固定属性、全技能・全習得Lvへの対応を検証する。実際のブラウザでは習得・詳細・装備・パッシブ・奥義・仲間切り替えを確認する。
