# 防具の部位アイコン

English Quest 用の32×32px・透過PNG。防具は次の4枚だけを使用する。
同じ部位の装備は、名前・材質・軽装／中装／重装・レベル・レアリティを問わず同じ画像を共有する。

| 装備の `slot` | 共通画像 | モチーフ |
|---|---|---|
| `head` | `head.png` | 銀の兜 |
| `arm` | `arm.png` | 銀の腕当て |
| `body` | `body.png` | 銀の胸当て |
| `cloak` | `cloak.png` | 赤いマント |

`js/ui/equipment-icons.js` の `armorIcon(slot)` で部位から画像を選ぶ。
`equipmentIcon(def)` は武器を既存の武器種アイコンへ、防具を上記4枚へ振り分ける。
画像は32pxのまま、`image-rendering: pixelated` で表示する。
名前を併記する装飾画像として扱い、読み上げを重複させない。

## 制作方針

組み込みの画像生成で各部位を1枚ずつ制作し、32pxへの縮小と既存武器パレットへの色合わせを行った。
採用したプロンプト全文は [generation-prompts.json](generation-prompts.json) に保存している。
共通の指定は、粗い32×32論理グリッド、暗紺の輪郭、白〜灰紫の金属、暗赤の革や布、少量の金色、透過背景。
滑らかな線・グラデーション・文字・背景の装飾は入れない。

- 頭：顔や人物を描かず、暗いバイザーを持つクラシックな銀の兜。
- 腕：手指や握り拳を描かず、前腕を覆う銀板と革のストラップで構成した腕当て。
- 体：頭や手足を描かず、肩当てと銀の胸板を中心にした胴鎧。
- マント：人物を描かず、首の開口、小さな金の留め具、裾に広がる暗赤の布で構成。
