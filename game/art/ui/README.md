# 町のドット絵アイコン

`facilities.png` は背景透過の4列×3行アトラス。左上から行優先で次の12種類を収める。

| 上段 | 2段目 | 下段 |
|---|---|---|
| ギルド酒場（ジョッキ） | 道具屋（薬瓶） | 闘技場（トロフィー） |
| 宿屋（ベッド） | 武器・防具屋（剣と盾） | 銀行・投資（袋と金貨） |
| 神殿（柱と屋根） | 工房・調合（金床と鎚） | 図鑑（本） |
| パーティ（青い盾） | 倉庫（宝箱） | 実績・称号（メダル） |

`js/ui/pixel-icons.js` と `css/pixel-ui.css` が32pxの表示に切り出す。
施設名を隣に表示するため、画像は装飾として扱う。下部ナビでも同じ素材を共用する。
武器種や防具部位の既存アイコンは、従来の専用PNGを使用する。

組み込みの `image_gen` で制作。暗紺の輪郭、銀・くすんだ金・暗赤・木の色を基調とする。
採用プロンプト全文とセル順序は `generation-prompts.json` に保存。
