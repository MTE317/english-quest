# English Quest データ（★12・バランス／ビルド調整版）

シミュレーションとゲームの両方が読む「正」のデータです。バランス目標は検証条件により変わるため、実測結果は [バランス調整レポート](../docs/balance-report.md) で条件とともに確認してください。
上級ジョブ・特殊ダンジョン・レジェンド級の装備はここに入っていません（ネタバレ防止のため別ファイル）。

## 決まりごと

- CSV の文字コードは UTF-8（BOMつき）。JSON はBOMなし。Excelで開いても文字化けしません。コードで読むときは先頭のBOMを取り除いてください。
- 1列目は英字のID。ほかのファイルからはIDで参照します。日本語の名前は自由に変えてかまいません。
- 1つのセルに複数の値があるときは `|` で区切ります（例：`fire|slash`）。
- 素材と個数は `素材ID:個数` の形にします（例：`goblin_mat:2|cave_rat_mat:2`）。
- 適正の `×` は装備できないことを表します。空のセルは「なし」です。
- スキルの細かい効果は skills.csv の effect_json に書きます。仕様書の数値とずれたときは CSV を正とします。

## 単語について

`lexicon.csv` は現在、英語面接の準備用の90語です（★1〜★3に30語ずつ、優先度Aの語を先に並べた。2026-11-22 入れ替え）。単語約12,000語＋フレーズ約3,000を約500個のルーンストーンに分ける案は、将来の教材拡張構想です。★4〜★12の戦闘データがあることと、同じ範囲の教材を収録していることは別です。

今回の戦闘調整は本体JSと現在のデータに基づき、正答率65%・80%・95%などの条件を分けて検証します。旧長期モデルの「★が1つ上がるごとに正答率が3%下がる」（`accuracy_drop_per_rank`）、15,000語を仮定したSランク到達年数、旧教材での習得率などは、現在の90語教材を使った今回の実測結果ではありません。今回、Sランクまでの長期学習年数は再計測していません。

面接向けのフレーズを追加するときは、回答では `my`、質問では `your` など話し手に合った語を使います。`something` や `someone`、`X` などは、面接原稿に沿った具体的な対象・人物・数値に置き換え、詠唱のヒントも対応する表現にそろえます。

## ルーンストーンと確認テスト

- ルーンストーンは教材セットです。刻印・共鳴・輝きによる能力値、経験値、お金の補正は2026-11-23に廃止しました。
- `exams.csv` の `confirmation` は任意の確認テスト（20問・80%）。教材が1項目以上あれば受験でき、予習・過去の合否・経過日数を条件にしません。合否は学習の記録だけに使い、戦力・報酬・称号・教材・闘技場の出題範囲を解放しません。
- 過去の `awakening` 試験と覚醒記録は移行対象です。既存の学習記録を消さず、確認テストの履歴として引き継ぎます。
- `lexicon.csv` の項目を別の `stone_id` へ移すときは、その項目の `id` を維持してください。教材から一時的に外しても履歴は残ります。同じ綴りでも学ぶ意味・用法を変える場合や新しい文に置き換える場合は、新しいIDを使用します。
- 石の★・ダンジョン持ち込み条件・昇格試験の習得率条件は今回の変更対象外です。

## バランス目標と実装済みのルール

以下のペース・成功率は**設計目標**です。今回の計測値や、すべての編成・敵・正答率に保証される値ではありません。設定の正本は `balance.json` の `balance_targets`、計測条件と結果は調整レポートにあります。

| 項目 | 設計目標 |
|---|---|
| 通常戦1戦 | 15〜20問、4人でおよそ4〜5巡 |
| ボス戦1戦 | 20〜25問 |
| 標準ダンジョン一周 | 50〜65問・約5〜7分（1問6秒＋操作等30秒と仮定） |
| 標準の踏破率 | 適正育成・装備、正答率80%で約70%（検証範囲65〜80%） |
| 敵に合わせた準備後 | 踏破率85〜95%を目標。準備や編成による大きな差を認める |
| 成長の間隔 | 成功した冒険2〜3回で、レベル・技能・装備のどれかに進展 |

- 旧「通常戦2〜3巡・6〜12問」、職別の2〜3倍ダメージ補正、旧長期学習モデルの合格記録を今回の目標や実測として流用しません。
- 公開14ジョブの `dmg_mul` はすべて1.0。本体JSはこの列を後掛けしておらず、能力値・武器適性・技能・装備効果で差を作ります。
- 新規パーティの共有資金は `new_game.gold = 1000`。既存セーブの所持金には遡って加算しません。
- 魔法剣士は崩れた砦、精霊術士は風鳴りの峡谷で、ボス撃破時10%の早期発見を維持しつつ3回目の踏破までに発見します。`discover_guarantee_clears = 3` を公開の発見2職だけに設定し、既存の `game.cleared` に今回のボス撃破を加えて判定します。全滅・途中帰還用の新カウンタは作りません。列が空の行は従来の確率判定だけです。
- 全滅では遠征開始前の資金・持ち物・経験値・AP・日数・依頼進捗へ戻します。学習・詠唱とJP、実際に得た魔物の遭遇・弱点・耐性知識は保持します。

## クエスト掲示・受注・保証金

- `quest_board.size = 6` が未受注の掲示枠です。受注上限とは別に扱い、初期3件、★4で4件、★8で5件へ増やします。
- `type_slots` は討伐2・採集2・ボス1・賞金首1を基本とします。現在の★・季節・行き先に存在する対象から生成し、同じ対象の契約を重複させません。
- 新規の通常討伐は地域の通常・季節モンスター3〜5体、採集はその地域の通常素材2〜3個。特定種討伐の旧セーブも引き続き達成できます。
- 討伐・採集・ボス退治は無料。賞金首は掲示報酬の10%を受注時に預けます（端数切り上げ）。達成報告で保証金全額を報酬とは別に返還し、自主放棄は80%返還（端数切り捨て）です。
- 全滅や途中帰還で契約を自動失敗にしません。期限なし。受注時の預かり額を契約に保存し、達成・放棄した契約を除去して二重返還を防ぎます。旧セーブの保証金未記録の契約は0Gとして扱います。
- 受注・報告で空き候補を補充します。同じ内容は、その帰還期間に受注・報告・放棄しても次の帰還まで再掲しません。帰還・踏破で更新するのは未受注の候補だけです。

## 短い遠征と出現の重み

| ダンジョン種別 | 階・戦闘数 | 日数 | 帰還ポイント |
|---|---:|---:|---|
| 近場 | 2 | 1 | 1階の後 |
| 標準・素材の宝庫・季節の地 | 3 | 2 | 2階の後 |
| 深層 | 6 | 3 | 3階の後 |

- 60か所の合計は204階・204戦です。1階1戦とし、最終戦をボス1体＋取り巻き1体、通常戦は初階2体・以降3体で構成します。
- `layout_version = 2` の新規遠征は短縮後の配置を使います。途中の旧セーブには `legacy_layout` の旧配置を使い、戦闘中の階や敵を突然入れ替えません。
- `encounters.common_count = 6` の常連へ、基本抽選重みの80%を配分します。候補から他種を削除する方式ではなく、季節種や珍しい敵にも重みを残します。季節は全地域で適用します。
- 同じ戦闘で同種が続くと重みを下げ、旧契約で討伐を求められている特定種は重みを上げます。このため実際の出現比率は基本80%から変わることがあります。
- エリートは★2以降、対象となる通常敵へ6%で付与し、一戦・一周に最大1体。ボス・賞金首の戦闘では重ねません。
- 賞金首依頼を受注中は、該当地域で一周40%の出現を狙えます。通常の出現率は `drop_tables.csv`。賞金首は道中の通常敵一体と置き換え、最終ボスとは同時に出しません。
- お金は一周の予算を遭遇の重みへ分配するため、短縮前の戦闘数を前提にした報酬計算を残しません。

## 武器16種の追加ルール（2026-11-23）

- `weapon_types.csv` の `dual_wield` は明示的な 1/0、`attack_stat` は `phys`（STR・敵DEF）か `mag`（MAG・敵RES）。`traits_json` にはCSVとしてエスケープしたJSONを格納。
- 既存14種＋新規 `scythe`（鎌、斬撃・両手）と `fan`（扇、風属性・片手だが二刀流不可）の16種。鎌・扇は各24段階（`scythe_t1`〜`t24`、`fan_t1`〜`t24`）。★ごとに店で買える前半とドロップできる後半がある。
- `traits_json` の設定例：`normal_status`（通常命中時の状態異常）、`vs_status`（指定した状態異常の敵への武器攻撃のダメージ補正）、`splash_chance` と `splash_mul`（槍の別敵への貫通）、`weak_damage_mul`、`blind_miss_mul`、`normal_all_mul`、`material_drop_mul`、`heal_mul`、`mag_mul`、`str_mul`、`song_bonus`、`party_buff_mul`、`weapon_skill_mp_mul`、`weapon_skill_mul`。
- 鎌は通常攻撃で出血15%、出血中の敵への武器攻撃+10%。扇はMAG依存の風通常攻撃、味方全体強化スキルの数値×1.10。剣は武器技能のMP消費×0.9、大剣は武器技能の威力×1.1、槍は30%で別敵へ65%の貫通ダメージ。これらは後述のボス耐性・発動回数上限と合わせて処理します。
- 武器熟練度は装備条件にせず、種別ごとの威力ボーナス（30体ごとに+2%、最大+20%）に使う。

## ビルドの効果と発動条件

- `enchant_sources.csv` の素材種族ごとの `families` と、`affixes.csv` の部位別 `stat` の両方を満たす効果だけ付与できます。素材側に効果名があっても、その部位に対応する行がなければ選べません。ボス素材の `ANY` も部位条件を越えません。
- 二刀流の副武器攻撃は通常攻撃だけです。通常攻撃時の固定状態異常は、主手・副手それぞれが当たったときに判定し、攻撃技能から副武器の固定状態異常は発動しません。
- 追撃と装備による通常攻撃MP回復は一行動に一回まで。HP吸収は実際に減らしたHPから計算し、一行動の回復量にも上限があります。反撃は物理被弾時のみで、反撃から追加状態異常・追撃・吸収を連鎖させません。
- `DOT_POWER` と `dot_power` は付与者の継続ダメージ強化、`STATUS_RATE` と `stat_rate` は付与率を補助します。毒・出血などは付与時の本人の強化を保存し、合計ダメージにも上限を適用します。`VS_DEBUFFED` は状態異常だけでなくDEF低下などの弱体にも対応します。
- ボスには状態異常と行動封じで別の付与補正を設け、行動封じの繰り返しと連続拘束を制限します。毒・出血は継続ダメージを軽減し、死の宣告・石化などの個別無効も管理します。上限の数値は `battle_formulas` が正です。
- 剣気は武器の攻撃属性を選んだ魔法属性一つへ置き換えます。扇と `PARTY_BUFF_POWER` は全体強化に適用し、歌の持続延長は吟遊詩人の全体強化、舞の持続延長は踊り子の全体強化に適用します。
- 励ましの `transfer: true` は、自分のMPを相手に渡します。技能の消費MPに加えて、渡した実量も使用者から減ります。吸魔も、回復量がその技能の消費MPを超えない扱いです。
- `build_guides.json` の8案は公開の基本・中級ジョブを対象とし、未所有・未習得でも読めます。ジョブ・技能・武器種・制作レシピのIDは実在データを参照し、付与素材例は工房の判定から選びます。説明は [ビルド手引き](../docs/build-guide.md) とゲーム画面で共通です。

## モンスター1,024体への拡張（2026-11-23）

- 既存384体のID・弱点・出現場所・素材は変更しない。通常モンスターを483体（60ダンジョンに各8体＋巡回3体）、季節限定を144体（春夏秋冬各36体）、闘技場の専用ボスを13体追加。
- `monsters.csv` の role は `normal / season / boss / bounty / arena`。闘技場ボスは通常エンカウントしない。
- 素材は原則★と主種別が一致する既存の共通素材を再利用し、存在しない組み合わせや各ダンジョンの代表種・季節種には新素材を追加する。`materials.csv` の `source_monster` はエンチャント素材の種別判定に使う。
- `arena_tiers.csv`（13階級）、`arena_battles.csv`（65戦）、`arena_shop.csv`（交換装備）を登録。各階級の第5戦に専用ボス。闘技場ボスから通常の素材・金・経験値は取得しない。
- 今回も総数1,024体と既存IDを維持し、遭遇の重み・敵の戦闘式・ボスの行動と耐性を調整しています。全モンスター・全編成で同じ難度になるという保証ではなく、測定条件と残る課題を調整レポートに記録します。
