# 追加職22〜24 実装記録

設計正本は [追加職19〜24技能詳細](additional-jobs-19-24-skills-v1.md)。召喚士・ドルイド・占星術師の各15技能、計45技能を神殿Lv6で解放する。

- 召喚士：炎・土・水の契約を1枠保持し、残回数と期限を管理する。契約の変更は回数を消費し、期限を延長しない。
- ドルイド：最大2つの種を本人の行動機会で育て、成長を消費する。獣化中は選択できる技能を制限し、再使用で行動を消費して解除する。
- 占星術師：通常予兆2枠と奥義の追加2枠を戦闘内に保存し、本人の行動終了時に予約対象へ一度だけ解決する。攻撃予兆には予約時のMAGと術補助を保存する。

契約、種、獣化、予兆は戦闘保存データだけに置き、戦闘不能・戦闘終了で消去する。技能データは `node scripts/build-additional-job-skills.mjs` で再生成する。
