# 戦闘共通計算（2026-11-25）
- 味方への異常・能力低下・敵の妨害は共通付与率を使用。基礎率×(1−加算耐性)×個別乗算耐性×(1−全体予防率)。加算耐性は0〜100%。毒無効は別途優先。敵からの付与率は最大100%。
- 敵への異常・攻撃後の能力低下は基礎率×正誤補正×付与補正（該当時）×相性×ボス補正。相性は2/1.5/1/.5/0、上限95%。ボスは通常異常.75、行動封じ.45、同種成功ごと半減、直後の行動封じ保護あり、石化・死の宣告無効。
- 能力補正は基礎値×(1＋上限内の強化合計−上限内の弱体合計)。現行上限は強化100%、弱体50%、ボス弱体30%。火傷のSTR低下も弱体上限に含める。敵の攻撃・防御・行動順も同じ補正関数を使う。
- 同一技能の弱体は強い値を優先し、同値なら長い残り時間を保持。異なる新マスター技能は加算し上限適用。旧バフ格納形式は互換維持。
- 通常ダメージ式、属性の最有利判定、会心、乱数、武器特性、DEF貫通上限70%、直接軽減70%、属性軽減80%、敵直接攻撃の軽減後最低割合8%は既存維持。8%は防御計算後の割合であり属性無効の味方攻撃には適用しない。
- 今回は全旧技能の格納形式・持続時間の移行、全効果の発動順の再設計、数値バランスの再計測は対象外。回帰テストを追加したが実行は別途必要。
