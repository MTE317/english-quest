# 地域1：モンスターの名前・グラフィック制作資料

39種の名称を確定。表示名の正本は [monsters.csv](../data/monsters.csv)、制作メタデータは [monster_art_reference.json](../data/monster_art_reference.json)。

旧名・モチーフを残し、名前だけでは姿が分からなくても制作できるようにする。外見は今後の制作向けの案であり、現在の画像の描写ではない。既存の技・種族と矛盾しない範囲で配色や細部は調整できる。スクルはリス型（nut_squirrel）。画像は表示名ではなくモンスターIDで対応付ける。数値・配置・技・討伐履歴用IDは変更しない。

この資料は制作向け。ゲームの図鑑に外見説明を新規表示する変更ではない。すでに保存された戦闘内の名前は、その戦闘が終わるまで旧名が残る場合がある。
