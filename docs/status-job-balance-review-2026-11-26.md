# 状態異常の計算式変更と職業バランスの確認

確認日：2026-11-26（日本時間）。対象mainコミット：`969a84ff1d12f71d7fee298aa1145dbc72b1343c`。比較元：`e2c7461b76b31d9efa7ee7d9029b8fa1462184e8`。

## 結論

今回の式変更だけを理由に、実装済み基本8職・設計済み追加9職の技能数値を一律に上げ下げする必要は見つからなかった。敵向けの係数は同じで、通常の付与・相性・ボス補正を比較した17,520条件の差は0。技能CSVのblobも変更前後で一致している。

変わるのは、味方の加算耐性の上限が90%から100%になったこと、および状態異常・能力弱体の付与経路を共通化したこと。合計加算耐性が90%以下の帯は従来と同じ。90%超では残る付与率がさらに下がり、100%では0になる。これは完全ガードを許す方針どおりで、敵の付与率を引き上げて打ち消す調整はしない。

**確認時点で、基本8職120技能は実装済み、追加9職135技能は設計段階。追加9職の実戦や勝率を検証済みという意味ではない。**

## 確認した式

味方への付与率：

```text
clamp(基礎付与率 × (1 − clamp(加算耐性, 0, 1)) × 各乗算軽減の残存率, 0, 1)
```

加算耐性には能力値・装備・共有パッシブ・一時的な加算耐性等を含む。LUK由来の基礎耐性とRESの魔法防御を混同しない。20%乗算軽減は残りに0.8を掛ける効果で、耐性を20ポイント上げる効果ではない。敵へ付与する確率の上限は95%、味方が受ける確率の上限は100%、味方の加算耐性上限も100%。この3つは別の値。

基礎付与率50%の例（全敵が50%という意味ではない）：

| 加算耐性 | 予防なし | 20%乗算軽減あり | 30%乗算軽減あり |
|---|---:|---:|---:|
| 0% | 50% | 40% | 35% |
| 50% | 25% | 20% | 17.50% |
| 80% | 10% | 8% | 7% |
| 90% | 5% | 4% | 3.50% |
| 95% | 2.50% | 2% | 1.75% |
| 100% | 0% | 0% | 0% |

20%と30%の乗算軽減を重ねると残存率は0.8×0.7＝0.56。軽減率を50%へ単純加算しない。加算耐性50%・基礎付与率50%なら、付与率は25%から14%になる。

## 実装済み8職への影響

- 騎士「不退の覚悟」の30%／50%／50%は乗算軽減のまま。Lv3は50%を3行動維持する。例えば加算耐性80%・基礎付与率50%なら、Lv3で10%→5%。単独では完全ガードを新しく作らない。
- 武闘家「不屈の体」のスタン耐性は加算。Lv5の20%と基礎等の合計80%を組み合わせると100%となり、スタンを完全に防ぐ。恐怖など別の異常まで同時に無効化する効果ではない。継承できる装備パッシブなので現職だけの優遇ではない。
- 「救援の決意」・「逆境の闘気」・「逆境の魔力」・「救護の決意」・「逆境の歌声」・「支える声」は、対応する異常が味方側へ新しく付かない構成ほど発動機会が減る。完全ガード構成で異常中限定の効果も常時得られるようには変更しない。装備枠・異常を受けるリスクとの選択関係を維持する。
- 100%耐性は予防であり、既に付いている毒・呪い等を自動で消す効果ではない。治療・既存の持続・行動可否は別処理。

基本8職の素LUK由来耐性をLv1／10／30／60／99で計算した40条件は約13.60%〜30.77%。素の耐性だけで100%になる職はなかった。装備・共有パッシブ等を加えた完全ガードは可能だが、装備の入手難度・強化費用・ステージごとの普及率は今回評価していない。

## 設計済み9職への影響

| 職業 | 確認結果 | 対応 |
|---|---|---|
| 聖騎士 | 静穏の祈り20%は残り付与率への乗算。完全ガード対象に追加効果はないが、加護・回復・反撃の中心機能は別。 | 付与率据置。式の加算／乗算の記載を明確化 |
| 暗黒騎士 | 出血付与35%は通常敵35%、相性通常のボス26.25%。HP費用・吸収の条件は味方の状態異常耐性と別。 | 変更不要 |
| 狂戦士 | 傷を恐れぬ者は新しい自己異常が防がれるほど発動機会が減る。怒気・鎮心の中心機能は異常を要求しない。 | 完全耐性構成では条件パッシブを選び直す設計を維持 |
| 侍 | RESの増減は直接魔法の防御能力であり、LUK由来の状態異常耐性そのものを増減する効果ではない。 | 構え・武器技の数値変更不要 |
| 剣闘士 | 挑発85%は相性通常ボス63.75%。挑発無効でも個人の決闘指定は成立する設計。束縛は行動スキップではない。 | 部分的な妨害として据置 |
| 僧兵 | 合掌の備え30%は一度の付与判定への乗算軽減。加算耐性＋30ポイントには変えない。 | 完全ガードで使い切る処理などは実装時に確認 |
| 修験者 | 不動の呼吸30%・耐苦の自己異常条件は耐性構成で価値が変わる。調息・気功・自己維持は異常不要。 | 乗算率据置。空治療で整息を得ない条件を維持 |
| 処刑人 | 怯ませる眼50%／低HP時70%は相性通常ボス37.5%／52.5%。恐怖は攻撃技能制限で、全行動停止ではない。 | 低HPの仕留めを中心とする数値を維持 |
| 忍者 | 分身の回避・身代わりは状態異常耐性とは別の判定。撒き菱の束縛40%は相性通常ボス30%。 | 忍術・分身の数値変更不要 |

新9職の敵向け妨害は、出血・能力弱体・挑発・束縛・恐怖の範囲。この設計から、新たな睡眠・凍結等の完全な行動停止技を追加する変更はしていない。ボスの免疫、完全制御の1行動制限、連続成功による減衰・保護期間は現行のまま使う。ここでいう完全制御と、恐怖・束縛等の一部の行動制限は区別する。

高い耐性を持つ相手への予防は「相対的に同じ割合だけ残りを減らす」が、元の付与率が低ければ絶対差は小さい。静穏の祈り・合掌の備え・不動の呼吸について、1行動とMPに見合うかの最終判断は、追加9職の実装後に敵の付与頻度・持続・損失行動数を含む模擬戦で行う。現時点で予防技能を加算耐性へ置き換えたり、率を一律に上げたりはしない。

## 検証方法と限界

- 最新のCSVパーサーと付与率・パッシブ計算の関数を取得したソースから抽出し、制御入力で実行した。敵側は73件の技能段階の状態付与源を、相性5段階・通常／ボス・既成功回数・保護期間・正誤倍率・付与補正で展開して17,520条件を比較。攻撃に付随する付与率は、必要な命中・実ダメージが成立した後の条件付き確率。
- 味方側は20状態＋能力弱体、加算耐性7段階、基礎率4段階、乗算軽減5構成で2,940条件を確認。騎士・武闘家の実技能データから17条件も別途確認した。複数人のパーティーパッシブ・毒専用無効はこの制御入力で0／無効なしに固定している。
- 追加9職は設計上の付与率を現行の共通式へ入れた投影であり、未実装の反応・資源・AI・持続処理を動かしたものではない。
- ローカル実行環境への接続が途中で失われたため、Nodeの全テスト、実戦の保存／再開、ダンジョン勝率は実行していない。旧環境の過去の成功テストを今回の実行結果として数えていない。
- 設計生成はメモリ内の入出力で実行し、現行技能CSVのID・名前を比較元に構造確認した。出力した技能定義・装備例・構成集計が元の設計JSONと一致することを確認した。

詳細な制御入力・付与率・投影値は[検証結果JSON](specs/status-job-balance-review-2026-11-26.json)。
