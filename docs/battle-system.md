# 戦闘システム詳細仕様

## 1. 適用範囲と読み方

ゲーム全体の前提は [ゲーム概要の「戦闘」](game-overview.md#5-戦闘)、実装の作業順は [実装チェックリスト](checklist.md)、調整の履歴は [バランス調整レポート](balance-report.md)、個別ビルドと既存21種を維持した実装判断は [36ビルドの設計・検証](build-catalog.md) を参照。ここでは戦闘内の効果の相互作用と、設計・実装の差分を扱う。

- **決定済み**は設計チャット末尾の合意・取りまとめから確認できる方針。
- **暫定値**は調整用の初期値。現行の設定値は「現行」と明記する。
- **未決定**は今後判断する事項。**合意未確認**は設計チャットの前半を取得できず、合意の有無を確認できなかった事項。
- **現行**は GitHub の main（照合時点 `d2c793b9`）のブラウザー版とデータを静的に確認した結果。Python シミュレーターとの一致やプレイ結果はこの表記に含めない。

## 2. 攻撃属性と相性

**決定済み**。攻撃属性は物理3種と魔法9種。攻撃属性は対象ごとの相性を決め、物理・魔法の計算区分は参照する能力や防御を決める。物理武器に炎を付与しても物理攻撃の区分を維持する。

| 区分 | 属性（データID） |
| --- | --- |
| 物理 | 斬撃 `slash`、刺突 `pierce`、打撃 `blunt` |
| 魔法 | 無 `none`、炎 `fire`、氷 `ice`、風 `wind`、土 `earth`、雷 `thunder`、水 `water`、光 `light`、闇 `dark` |

| 表示 | 意味 | 設計値の根拠 |
| --- | --- | --- |
| ★ | 最も有利な段階 | 弱点2.0倍の例あり。★の正式倍率は合意未確認 |
| ◎ | 弱点 | 複合属性の例で1.5倍 |
| 〇 | 等倍 | 複合属性の例で1.0倍 |
| △ | 耐性 | 設計倍率は合意未確認。現行は0.5倍 |
| × | 無効 | 複合属性の例で0倍 |

**決定済み**。複合属性は対象に対する最も有利な倍率を採用する。斬撃1.0倍と炎1.5倍なら1.5倍。斬撃0倍と炎1.5倍でも1.5倍で、すべて無効なら0。無属性も魔法属性の一つで、耐性強化の対象にできる。

**現行**。 [属性マスター](../data/elements.csv) に12種あり、 [戦闘コード](../game/js/battle.js) の一般攻撃は `weak` で1.5倍、`resist` で0.5倍、それ以外と無属性は1.0倍。無効の設定値は存在するが、一般の相性関数で使用していない。一般の複合属性は倍率の算術平均。最適属性を選ぶ個別スキルには別処理がある。

### 3.2 付与率・耐性・ボス

**決定済み**。攻撃属性耐性は被ダメージ、状態異常耐性は付与成功率に作用する。追加の状態異常耐性は相対的に減算する。たとえば追加耐性を適用する前の成功率60%に対して毒耐性50%なら `0.60 × (1 − 0.50) = 0.30`。耐性強化は図鑑の相性表示とは別の効果。状態異常専用スキルは回避判定の対象から外す方針。

**現行**。味方から敵への付与は、発生源の基礎率に回答補正と付与補正 `(1 + statRate)` を掛け、ボス補正後に上限を適用する。敵から味方への付与は、無効化効果の判定後、敵の基礎率に `max(0, 1 − 状態異常耐性)` を掛ける。耐性には対象の能力・味方のパッシブ・全異常と該当系統の香が関与する。基礎率は発生源の設定を使い、表の30%・50%などの行動変化率とは別に判定する。

**現行のボス制限**。石化・死の宣告は設定で無効。それ以外の一般異常の付与率は0.75倍、行動制限は0.45倍。通常の付与率上限は95%、味方側の状態異常耐性上限は90%。行動制限の同一効果は成功回数ごとに付与率が半減し、成功時の持続は1ターン。付与後には次ラウンドまで行動制限の再付与を防ぐ。ボスの継続ダメージ補正は0.65倍で、継続ダメージには最大HPの12%を基準とする上限設定がある。係数は [バランス設定](../data/balance.json) の `battle_formulas` と `boss_patterns` を参照。設計上の最終係数と制限対象の全リストは合意未確認。

### 3.3 持続・重ね掛け・治療・連戦

- **決定済みの範囲**。自然解除・道具・スキル・神殿の治療と戦闘間の治療を想定する。持ち越す効果を短期効果と区別する。
- **現行**。味方の短期異常は行動開始側で残りターンを減らし、敵の異常は敵の行動終了側で減らす。味方への毒の再付与は最大3段階まで加算して期間を更新する。他の多くは再設定。敵への付与では残り期間と威力の更新ルールが異なる。戦闘中の治療は道具・スキル名とマスターの `cure` を照合する経路がある。
- **現行**。戦闘終了時に持ち越し指定の状態を味方の保存データに残す。戦闘オブジェクトの一時効果は次の戦闘へ移さない。既存の呪い・石化・衰弱には神殿・万能薬の記載がある。
- **合意未確認**。20種ごとの持続・最大段階・上書き条件、持ち越し対象、戦闘間で使える治療と料金、戦闘不能や撤退時の消去規則。現行値をそのまま設計値に転記する前に確認する。

## 4. 英語クイズと処理順

**決定済み**。通常の手動行動と自動処理を区別する。混乱・魅了による自動行動、反撃、その他の自動発動には追加の英語問題を挟まない。魅了を解くための回答と、回答後に置き換わった自動行動の処理は別。両状態が同時にある場合の優先、混乱の対象範囲・クイズ出題前に行動を差し替える条件、魅了の正解時に元の行動を続ける条件は合意未確認。

**現行**。味方の行動は問題を予約し、回答後に解決する。正解は効果倍率1、不正解は原則0.1〜0.5倍（個別処理あり）。通常攻撃が正解なら最大MPの5%を回復する。魅了は先に判定し、正解で解除して後続判定へ進む。不正解は味方への攻撃に置換。混乱は道具以外の予約行動で判定し、発動時は自分を含む味方への攻撃に置換する。敵の混乱・魅了は行動不能の確率判定で処理する。

決定済みの局所的な順序は次のとおり。

1. 行動開始で継続ダメージ・MP減少を処理し、その後に自動再生。睡眠・凍結中も再生し、戦闘不能・石化中は停止。呪いはHP再生を止める。
2. かばうが成立した場合は受け手を変更し、変更後の対象の防御・耐性・障壁を参照する。暗闇による命中失敗と受け手の回避は別判定。
3. 直接ダメージは割合軽減、障壁の吸収、HP減少の順。対象変更は攻撃に付随する状態異常にも適用する。
4. 反撃は元の攻撃への反応として処理し、追加のクイズや反撃の再発動を起こさない。

**未決定**。全体の処理順は整合性確認待ち。命中失敗と回避の優先順位、障壁で全吸収した場合の異常付与・被弾時反撃、致死ダメージ・回復・解除・反撃の優先順位、複数ヒット・複数対象での反撃回数の数え方を詰める。

## 5. 能力バフ・デバフ

**決定済み**。STR（物理攻撃）、MAG（魔法攻撃）、DEF（物理防御）、RES（魔法防御）、SPD（行動順）の5能力を戦闘中に増減させる。会心・回避などは次節の特殊効果として扱う。設計上の能力ごとの倍率・継続・上限・同能力の強度と期間の更新・相殺規則は合意未確認。

**現行**。味方の同じ保存枠に同じキーを付与すると、強い値を優先し、同じ強さなら長い残り期間を優先する。全体バフと個人バフは別枠で、基本5能力の上昇合計は `battle.buff_cap`（60%）を適用。能力ダウンは別倍率で適用する。敵の個別デバフは値と期間を保持し、ダメージ計算で参照するものの上限設定は50%。経過単位は味方のバフ、敵のデバフ、状態異常で共通化されていない。

## 6. 特殊補助効果（9系統）

**決定済みの共通方針**。スキル・アイテムによる一時効果は戦闘終了時に解除する。装備・エンチャント・パッシブの常時効果は発生源が有効な間続く。複数の効果は原則併用し、上限を共有する。障壁は耐久値を加算しない。一時効果の原則3ターンは暫定値。

| 系統 | 決定済みの挙動 | 暫定値 | 現行との照合 |
| --- | --- | --- | --- |
| 会心 | 物理・魔法の直接攻撃で発生し、弱点倍率と併用。継続ダメージ・回復・補助は対象外 | 会心率強化10〜20ポイント、最終会心率85%、基準1.5倍、倍率上限3倍 | 現行の会心率上限85%、基準1.5倍、倍率上限3倍。ヒットごとに判定。反撃でも通常攻撃の計算を参照 |
| 回避 | 直接攻撃を物理・魔法とも回避でき、全体攻撃は対象ごとに判定。束縛中は不可。暗闇とは別判定 | 回避率強化10〜20ポイント、上限60% | 味方側は直接攻撃を回避でき、現行の上限は60%。味方が攻撃する側の敵回避チェックは物理のみ |
| 自動再生 | 行動開始時にHP・MPを回復。継続ダメージや魔力漏出を先に処理。呪い中のHP再生、戦闘不能・石化中の再生は停止。戦闘終了後も回復分は残る | 最大HPの3〜5%、最大MPの2〜4%／ターン。加算するが具体的な上限は未決定 | HP再生経路あり。通常攻撃の正解によるMP回復は別機能。照合した行動開始処理に共通のMP再生・魔力漏出の経路は見当たらない |
| 障壁 | 物理・魔法の直接ダメージを吸収。継続ダメージは対象外。強い残量だけを採用し、破壊または期限で消失。呪い中も付与可能 | 最大HPの10〜20%、上限25%、原則3ターン | 超過回復を障壁に換える装備効果がある。現行は最大HPの20%まで、基準2ターン。強度優先で敵の直接攻撃を吸収。呪い中はこの経路で付与できない |
| ダメージ軽減 | 物理・魔法・全直接攻撃を区別。状態異常の確率とは独立、継続ダメージは原則対象外。障壁に先行 | 効果量10〜25%、合計上限70%を暫定基準 | 現行は割合軽減上限70%、属性耐性上限80%。かばうも含めた合成後に最低ダメージ割合8%を使う。設計との上限統一は未決定 |
| 反撃 | 被弾時と回避時を区別し、物理・魔法の直接攻撃が対象。通常攻撃を基準とし、属性相性・会心を適用。元の1行動につき最大1回。反撃の連鎖なし | 発動率の目安15〜30%。上限は未決定 | 被弾時・回避時の別経路あり。敵の魔法への被弾時反撃は現行コードで対象外 |
| かばう | 味方への物理・魔法の単体攻撃を1行動につき最大1回引き受ける。全体攻撃・自身への攻撃・行動不能者の発動は対象外。受け手の回避・反撃・障壁・耐性を適用 | 発動率30〜60% | ナイト・装備等の単体かばうあり。全体攻撃を除外し、候補の先頭を判定する。職の既定値と固有軽減がある |
| 属性付与 | 通常攻撃・武器依存スキルへ魔法属性を付け、ダメージ区分を維持。付与分は1種類で上書きし、固定属性のスキルは維持。装備の恒常付与は一時付与で切り替え可能 | 原則3ターン | 戦闘中の付与と装備由来の属性が存在。一時付与中の物理武器依存攻撃では武器の元属性を付与属性で置換する。原則3ターンの期限は付与処理に存在しない |
| 耐性強化 | 属性耐性は受けるダメージ、状態異常耐性は付与成功率に作用。異なる耐性を併用でき、同系統も上限付きで加算。時限分はディスペル対象。ダメージ軽減と共通の最終上限を設ける方針 | §6.1参照。原則3ターン | 属性・系統別の香、装備・パッシブ、上限設定がある。同一枠の香は強度優先。共通ディスペル、対象範囲と上限統一は要照合 |

### 6.1 耐性強化の暫定値

| 対象範囲 | 対象に適用する軽減・成功率減少 |
| --- | --- |
| 攻撃属性1種 | ダメージ30〜40% |
| 物理3属性または魔法9属性 | ダメージ15〜25% |
| 攻撃属性12種 | ダメージ10〜15% |
| 状態異常1種 | 成功率40〜60% |
| 状態異常1系統 | 成功率25〜40% |
| すべての状態異常 | 成功率15〜25% |

倍率2.0の炎弱点に炎耐性40%なら、その炎属性の補正は `2.0 × (1 − 0.40) = 1.20`。複合属性の最大倍率選択の前後どちらで耐性を反映するかと、軽減上限の算出方法は未決定。食い違いを検証する例は、斬撃等倍・炎弱点に対して炎耐性が十分高く、耐性適用後は斬撃倍率の方が高くなる場合。

## 7. 図鑑と探索での情報開示

**決定済みの範囲**。属性相性と耐性は、敵を調べて装備やスキルを選ぶ攻略情報にする。状態異常に対する一時的な耐性強化は、図鑑に表示する元の相性段階とは分ける。初遭遇・属性を試す・調べる・討伐の各条件で何を開示するか、未知と等倍の表示差、敵の状態異常耐性の開示条件は合意未確認。

**現行**。遭遇でモンスターを登録し、実際にダメージを与えた攻撃の属性を記録する。「調べる」で弱点を開示し、確認済みの属性は弱点・耐性・等倍として表示する。無属性はこの公開リストに含めない。戦闘中の確認画面と記録側の図鑑で参照できる。5段階や状態異常耐性の開示は、照合した図鑑表示のデータ構造にない。複合攻撃でどの属性を「確認済み」と扱うかは、最大倍率に切り替える際の確認項目。 [図鑑の開示処理](../game/js/monster-knowledge.js)
