## 共通ルール

- 表の `A01〜A09 / P01〜P05 / U01` は固定技能IDの末尾。各行の数値列は**Lv1から最高Lvまで順番**。Lv3は3値、Lv5は5値、Lv1は1値。前提のLvを省略した時はLv1。修得APは導入10、標準18、発展28、奥義50。Lv2以降の強化APは12/20/30/45。パッシブと奥義の通常MPは0。奥義は本人が同職の非奥義10種類を修得し、EX満タンで使用する。EXは既存の1戦1回制限を守る。
- `W` は本人のSTR＋装備武器威力による物理直接攻撃（相手DEF）。`M` はMAG＋術補助の直接魔法（相手RES）。`H` は既存のHP回復式、`R=floor(10＋0.5×使用者Lv＋使用者RES)` は防護基準。単体の「攻撃＋回復」でも攻撃は1回だけ。複合属性は1回の命中に対して有利な相性**1つ**だけを採用する。異なる物理・魔法属性を一撃に重ねない。
- HP/MP回復は各最大値で止め、防護の合計は対象最大HP50%、直接被害軽減の合計は70%、回避率は60%、MP費用軽減は50%の共通上限を守る。能力強化・攻撃強化は既存の同種上限と強い方1件の規則に従う。石化・敵の完全免疫・ボス補正を無視しない。蘇生は石化を治さない。
- 通常の強化は対象の次の2行動終了まで。本人の「次のN行動」は発動行動では減らさず、以後の本人行動機会（妨害による喪失も含む）で減らす。敵の「次のN行動」は敵行動機会で数える。英語の出題待ち、保存・再開、派生攻撃は行動を進めない。無効な対象・資源不足はMP/EXを支払う前に拒否する。正解倍率の扱いは既存戦闘式を用い、資源獲得には明記した実ダメージ・実回復などの成立を要する。
- 勇気・魔王化・極意・術式記憶・奇跡・覇気は本人ごとの戦闘内状態。他職へ技能を継承しても資源を作る技能と消費する技能の条件を同じように適用する。戦闘不能で資源と継続効果を消すが、**一戦中の獲得累計・使用済み回数は蘇生後も保持**する。全滅・戦闘終了ではすべて消し、次戦へ持ち越さない。途中保存では所有者・技能ID/Lv・対象・残量・期限・付与順・乱数状態を保ち、再読込で再発動・再消費しない。追加ターン、追加の英語問題、報酬や品物の生成は行わない。
- 伝説職の**解放条件は別途設計**する。ここで技能を記述しても転職可能にはしない。施設Lv、試験、個別試練、必要素材は世界進行と照合して決める。

## 継続検証と未確定事項

1. 既存の白魔道士、聖騎士、侍、黒魔道士、戦略家、狂戦士と、同レベル・同装備・6人編成で1枠ずつ交換し、単体／8体／ボス戦の平均必要回答数、MP収支、全滅率を比較する。伝説職の全体攻撃と全体防護が両方強すぎる場合は倍率と防護量から調整する。
2. 勇者・聖者の資源獲得は実回復、護衛、弱点実被害のイベントごとに上限を検証する。覇王は6人編成、複数覇王、代理攻撃、連撃、敵の反撃でも1巡1回に収まることを確認する。剣聖は同じ技・別の技・行動喪失・再読込による連続判定を確認する。
3. 魔王化と護符は、戦闘不能・石化・全滅・別の変身・再付与で期限や使用済み上限が復活しないことを確認する。賢者の記憶は複合攻撃の前後、対象全滅、セーブ直後、誤答、継承で複製されないことを確認する。
4. 伝説職の解放条件、専用試練・素材、職別の画像や技能アイコンは本書では確定しない。世界進行、神殿の上限、昇格試験の実装と合わせて別途設計する。数値は初稿であり、シミュレーションとテストプレイ後に調整する。
