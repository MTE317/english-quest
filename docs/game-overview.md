# English Quest 仕様のまとめ（コーディング用）

元の仕様書は claude.ai の Docs にある。ここはコードを書くのに必要な要点だけをまとめたもの。数値はすべて `data/` が正で、ここに書いた数値は目安。

最終更新：2026-11-22

## 1. 目的と規模

- 学習の目的：英語の単語とフレーズを覚えて、語彙力を増やす。
- ゲームの目的：クエストをこなしてレベルを上げ、**Sランク冒険者**になる。
- 覚える量：単語約12,000語＋フレーズ約3,000（句動詞・熟語とイディオム・会話フレーズ）。英検1級相当を物差しにしている。
- ★（ダンジョンと単語の等級）は12段階。★ごとに英検の級を目安として対応させる。
- 目安の時間：1日15分で約5.5年、1時間で約1.4年。

## 2. ルーンストーン（単語セット）と出題

| 学習の仕組み | ゲーム内の姿 |
|---|---|
| 単語セット | ルーンストーン（`rune_stones.csv`）。★が等級、テーマ別 |
| 1つの単語・フレーズ | ルーン（`lexicon.csv`） |
| 予習 | ギルドの資料室で「次のルーンを読み解く」（カード：英語・意味・例文・発音） |
| 習熟度 | 未解読 → 学習中 → 習得（文字が輝く） |
| 復習の時期が来た単語 | かすれたルーン（鍛錬でなぞると輝きが戻る） |
| セットの確認テスト | 覚醒の試練（合格で石が覚醒） |
| 図鑑 | ギルドの「石碑の間」 |

- ダンジョンに入る前にルーンストーンを1つ選んで持っていく。石の★はダンジョンの★以上であること。
- 出題は**復習優先**：かすれたルーン（どの石でも）を先に出し、残りを持ってきた石から出す。1回の遠征で初めて出す単語は10〜15語まで。かすれたルーンが多いときは新出を減らす（`srs.json`）。
- 復習の間隔：思い出せる確率が約9割に下がるころに出す（FSRS を参考）。正解で間隔が伸び、間違えると縮む。「習得」は日を空けて3回続けて正解（仮）。
- 誤答の選択肢：慣れないうちは別の石から、慣れたら同じ石の似た単語から。
- 問題の形：4択。英→日・日→英。フレーズは空欄埋め（look ___ the baby）と、場面に合う言い方を選ぶ形も。
- 報酬は学習の質で決まる：初めての単語や復習の時期が来た単語は多く、何度も正解した簡単な単語は少ない。

## 3. 試験（`exams.csv`）

- 覚醒の試練：石のルーンをすべて読み解くと受けられる。20問・8割で合格。落ちたら次の日に再挑戦。
- 昇格試験：冒険者の本ランクを上げるとき。その★の単語の8割を習得していることが条件。
- 最終試験：Sランク。ボス戦＋全範囲の総復習。

## 4. 刻印（`kokuin_slots.csv`・`rune_effects.csv`）

- 4人それぞれが「刻印」の枠を持ち、覚醒したルーンストーンをはめる。枠は神殿でお金か素材を払って増やす（最大6つ）。
- 効果は石のテーマとは無関係。覚醒したときにプレイヤーが系統（STR・MAG・DEF・RES・SPD・LUK・HP・状態異常の耐性・経験値・お金）を選ぶ。お金を払えば選び直せる。選んだ系統で石の色が変わる。
- ★の高い石ほど効果が大きい（1つで数%）。同じ系統を1人に3つはめると共鳴。
- 輝きのボーナス：はめた石のルーンがかすれていなければ効果が少し上がる。かすれても効果はなくならない。

## 5. 戦闘

- パーティは固定の4人。ターン制、隊列なし。行動は「通常攻撃」か「スキル」で、どちらでも4択の問題が1問出る。正解なら行動が成功、不正解なら弱い行動になる（倍率は `balance.json`）。
- 能力値：HP・STR・MAG・DEF・RES・SPD・LUK。派生ステータス（CRT・回避など）は仕様書の式。
- MP はダンジョンの中では自然に回復しない（共通パッシブで戦闘後に少し回復）。宿屋で全回復。
- 状態異常は21種（`status_effects.csv`）。属性12種（`elements.csv`）。モンスター種別18種と特効。
- 逃げる：行動の1つ。成功率の式は `balance.json` と仕様書。

## 6. ジョブ・スキル・装備

- 基本ジョブ8種（最初から使える）と中級ジョブ6種（素材か発見で解放、`job_unlocks.csv`）。上級ジョブは別管理。
- ジョブチェンジは町の神殿。スキルツリーは AP で覚える（`skills.csv`、効果は `effect_json`）。ほかのジョブのスキルも枠の範囲で持ち出せる。
- 装備枠は8つ（武器・頭・体・腕・マント・アクセサリー×2 ほか）。武器14種（銃・鞭を含む）。適正 S/A/B/C/×。
- レアリティ7段階とランダム効果（`affixes.csv`）。強化 +1〜+10、分解、振り直し。
- 制作装備にはエンチャント（最大2枠、素材で系統が決まる）。
- 熟練度：同じ種類の武器を使うと上がり、強い武器の装備条件にもなる。

## 7. ダンジョンと全滅

- ★と階層の2軸（`dungeons.csv`・`dungeon_floors.csv`）。途中に帰還ポイントがある。帰還アイテムもある。
- **全滅＝ダンジョンに入る直前の状態に戻る**：お金・素材・拾った装備・経験値・AP・使ったアイテム・日数がすべて戻る。救済はなし。学習記録は残る。
- 負けたら★を下げて鍛え直すのが基本（ゲーム内でヒントを出す）。
- ダンジョンの途中でセーブはできない（閉じたら自動保存から再開）。

## 8. 町と経営

- 施設：ギルド（クエスト・昇格試験・資料室・石碑の間・訓練場）、神殿（ジョブチェンジ・復活・状態異常の治療・刻印）、宿屋、店、工房（武器・防具・装飾）、銀行（融資のみ）、貸し倉庫。
- 暦：1年＝4か月（季節）。ダンジョンは日数を使う。月末に会費と倉庫代を払う。滞納すると借金（罰は経営面だけ）。
- 町への投資で施設のランクが上がる。
- 鍛錬：ギルドの訓練場。戦闘なしで5・10・15問をまとめて解き、キャラ1人の経験値かAPを伸ばす。かすれたルーン（復習）を優先して出す。**日数は進まない**。お金や素材は入らない。

## 9. 冒険者ランク

- ★ごとに本ランクと「＋」。本ランクに上がるときは昇格試験。最高はS（伝説）。ランクで挑戦できるダンジョンの★が決まる。
- 「＋」ランクにも特典をつける（商店の割引・クエスト報酬アップなど、`adventurer_ranks.csv`）。
- ★12に広げる作業中のため、今のCSVはまだ★5・11段階のまま。
