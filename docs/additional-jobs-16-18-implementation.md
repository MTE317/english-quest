# 追加職16〜18 実装内容

精霊術士・魔女・呪術師の45技能（成長段階143）を[設計書](additional-jobs-10-18-skills-v1.md)に沿って実装した。3職とも初期から転職でき、技能はAPで習得・強化する。習得技能は転職後も残る。

| 職 | 戦闘の仕組み |
| --- | --- |
| 精霊術士 | 風・土・水の「場」を戦場に1つ設置。場の属性に一致する直接攻撃の倍率と自分の魔法耐性を変え、入れ替え・防護・解放で使い分ける。 |
| 魔女 | 鎌の術補助値を加算した魔法を使用。追撃型または悪戯型の使い魔を契約し、自分の攻撃後に反応させる。使い魔は契約時の能力値を保存し、残回数・有効な行動機会で消える。 |
| 呪術師 | 敵ごと・術者ごとの呪印を付け、敵の行動終了後に反応させる。行動種類に応じた効果を持ち、残回数と敵の行動機会で消える。 |

場・使い魔・呪印は戦闘データとして保存され、再開後も残回数を維持する。戦闘終了・術者の戦闘不能時には消える。発動する資源を持たない技能は選択前に制限し、失敗時にMPを消費しない。戦闘画面には場・使い魔・呪印などの効果を表示する。

生成元は `docs/specs/additional-jobs-10-18-skills-v1.json` と `scripts/additional-jobs-16-18-plans.mjs`。`node scripts/build-additional-job-skills.mjs` でCSVへ反映する。挙動の検証は `node --test game/tests/additional-jobs-16-18.test.js`、全体の回帰確認は `node --test game/tests/*.test.js`。
