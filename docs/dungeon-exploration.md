# ダンジョン探索の共通仕様

現行60ダンジョンの経路は固定の一本道。必須戦闘枠は近場2、標準・素材・季節3、深層6で、最後の枠を既存のボスが占める。新規遠征では踏破済みでも最奥に同じボスが出現し、既存のボス報酬を毎回抽選する。通常戦のエリートと賞金首も既存の抽選に従う。旧育成遠征は保存済み経路で完走でき、帰還しても踏破数は増えない。開始済みの旧遠征には探索抽選を後付けしない。

## 発生と報酬

| イベント | 処理 |
| --- | --- |
| 宝箱 | 初回固定と周回抽選。初回は基準収入15%と通常素材2個。周回はコモン装備15%、通常素材1個35%、小額ゴールド35%、回復薬15%。道具上限や候補不足時は小額ゴールド。小額は基準収入4%（最低1G） |
| 採集 | 訪問中のダンジョンの通常・当季の敵が落とす通常素材を1個。素材ランクは行き先以下 |
| 休憩 | 生存者の最大HPの10%、最大MPの5%を端数切り捨てで回復。不足分が上限 |
| 隠し通路の発見 | 初回の固定地点で行き先の発見記録を得る |
| 調査地点 | 初回の固定地点で進捗フラグを得る。現行の配置は `SQ-1` |
| 帰還地点 | 経路CSVで指定の地点に毎回出現。町へ帰るか先へ進むかを選ぶ |

[balance.json](../data/balance.json) の `dungeon.exploration` で確率と報酬を調整する。下表の通常枠は互いに独立。発生した枠を最奥より前の階に重複なしで置き、宝箱45%、採集40%、休憩15%から抽選する。出発時に階・種別・報酬用の乱数種を保存し、戦闘・賞金首の乱数列には影響しない。固定イベントと帰還地点は通常枠の外。階の戦闘を終えて次へ進む際に自動処理し、既存の戦闘間画面に短い結果を表示する。通常戦の逃走は従来どおり階を進められる。

| 戦闘枠 | 通常イベント枠 | 1周の設計平均 |
| --- | --- | --- |
| 2 | 1枠・50% | 0.50回 |
| 3 | 1枠・80% | 0.80回 |
| 6 | 2枠・各80% | 1.60回 |

装備と素材は戦闘と同じバックパックの取得・入れ替え・倉庫への移送を使う。消耗品は既存の所持上限を適用する。ゴールドは遠征中の残高に加算し、全滅時は入場時の残高に戻る。宝箱から出る装備は通常ドロップ対象のコモンのみ。戦闘と同じ装備図鑑の登録処理を通る。

## 保存と世界解放

- 固定地点は `fixed[dungeonId]` に `id`・`floor`・`type` を指定する。初回箱は `chest` と `first: true`、発見は `discover` と `discovery`、調査は `investigate` と `flag` を指定する。識別子は公開後に維持する。現行配置は初回箱・調査・発見を各1か所。
- 帰還時に `game.exploration.events` へダンジョンIDとイベントIDの組を記録する。初回箱には確実に持ち帰れるゴールドが含まれる。満杯時の素材を見送っても、ゴールドを持ち帰れば初回取得が確定する。
- 発見事実は `game.exploration.discoveries` に保存し、調査等の条件フラグは `game.worldFlags` に保存する。任意の `entry[dungeonId]` に `discovery`、`flags`、`cleared` の条件を指定できる。通常のランク・経路条件と併用する。現行60地点の入場条件は従来どおりで、試験配置の発見は行き先を早期に知る手がかり。地理・方角・地図の接続線は判定に使わない。
- 途中帰還でも報酬と到達済みの固定記録を確定する。最奥ボスを倒して帰還した場合に限り踏破数を加算する。最奥ボスから逃げた場合は帰還か再挑戦を選べる。
- 全滅は入場時スナップショットに戻し、既存の学習記録・詠唱・JPは維持する。発見だけを全滅後も維持する案は保留につき、今回は発見も帰還で確定する。これにより全滅で世界解放の条件が進むことを防ぎ、発見だけの保持を将来検討する際にも入場条件と別に扱える。

世界地図の配置・霧と新しい地域データ、特殊クエスト本編は別作業。現行のルーンストーン制限・出題記録と6人表示を遠征画面で引き続き使う。
