# English Quest：基本8職・スキル表示文案 v1

基本8職・各15技能、合計120技能のゲーム表示用説明文案。対象・技の格・特徴を短く伝える。現行マスターの効果をもとに作成した文面案で、ゲーム画面への組み込みは別工程とする。

## 表記の方針

- 説明は原則1〜2文で、対象・技の格・特徴や重要な発動条件を伝える。
- 威力倍率・能力参照式・効果量の細かな割合は表示文に入れない。攻撃の格は通常・強・極大を基本とし、技の役割に合わせて表現する。
- 強さの呼び方は技ごとに固定する。通常のレベルアップでは強や極大へ自動で呼び替えない。
- 対象数・連撃数・使用回数・追加MP・発動に必要なHPやMPの残量は、判断に必要な場合だけ残す。
- 各職の一覧は修得時の文面。成長で対象や条件が変わる技能は、後半の差し替え文を使う。
- パッシブは装備中に有効。奥義はEX満タン時に使用する。これらの共通条件は各技能へ繰り返し書かない。
- 状態異常・弱体・挑発・盗みなどは成功判定がある。状態異常や弱体は相手の耐性・免疫にも影響され、盗みは盗品候補や取得済みかどうかにも制限される。
- 「防御を貫く」は防御力の一部を無視する意味。「支援の歌」は守りの歌・力の歌・疾風の歌・癒しの旋律の4曲。
