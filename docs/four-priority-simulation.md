## 再現コマンド

GitHubの基準コミットにこの計測専用ファイル群を置き、リポジトリのルートで実行。Node v24.22.1使用。結果にはソース指紋を保存し、集計時にバッチ間で一致を検査。保存済みの統合結果は、下記コマンドで置き換わる。

```powershell
$env:EQ_SIM_CACHE = '1'
$batches = @{matrix1=100;matrix6=100;matrix12=100;swapsA=32;swapsB=32;teams=100;encounters=100;niches=16;tuning=100;draft=32}
foreach ($batch in $batches.GetEnumerator()) {
  node --import ./sim/priority-main-loader.mjs sim/four-priority-engine.mjs $batch.Value 613301 "sim/results/priority-$($batch.Key).json" $batch.Key
  if ($LASTEXITCODE) { throw "Batch failed $($batch.Key)" }
}
node --import ./sim/priority-main-loader.mjs sim/four-priority-engine.mjs 1 613301 sim/results/four-priority-audit.json audit
node --import ./sim/priority-main-loader.mjs sim/four-priority-protocol.mjs
node sim/four-priority-model.mjs
node --import ./sim/priority-main-loader.mjs sim/build-probes.mjs --output sim/results/priority-existing-probes.json
node sim/four-priority-assemble.mjs
Remove-Item Env:EQ_SIM_CACHE
node --import ./sim/priority-main-loader.mjs --test game/tests/*.test.js
```

`four-priority-engine.json` の `all` は全試行、`clear` は成功のみ。HP/MP純消費は開始時と終了時の差で、回復が上回ると負。遠征の `hpNet/mpNet` は戦闘内の差の和、 `expeditionHpNet/expeditionMpNet` は戦間回復後を含む差。 `mpSpent` は手動1件の前後差の正部分で、同時回復による相殺と敵・強制行動の消費は含まない。状態付与では固定プローブが成功と試行を計測し、遠征集計では正解した付与技能の選択数と状態の変化を保存した。命中演出件数とCPU時間は一対一に対応しない。
