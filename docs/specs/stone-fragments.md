# 装備分解と強化石の欠片

装備を所持品から分解すると、レアリティに応じた強化石の欠片を1個得る。旧仕様のレアリティ別欠片と強化石Iの確定付与は廃止する。装備中の装備は外してから分解する。付与効果がある場合は、従来どおりエンチャント粉を効果2個につき切り上げ1個（最大3個）得る。

| レアリティ | 欠片 |
| --- | --- |
| コモン | 強化石Iの欠片 |
| アンコモン | 強化石IIの欠片 |
| レア | 強化石IIIの欠片 |
| エピック | 強化石IVの欠片 |
| レジェンダリー／アーティファクト／オリジン | 強化石Vの欠片 |

固有装備（ユニーク）はレアリティ表の対象外のため、装備★1～3ならI、★4～5ならII、★6～7ならIII、★8～9ならIV、★10～12ならVの欠片を得る。

強化時、同じ段階の欠片3個をその強化石1個分として使用できる。石を先に消費し、不足分を欠片で補う。欠片の余りは残す。必要な石の段階と個数、G、成功率は `enhance_rates.csv` の現行設定を使い、失敗時も石と欠片を消費する。欠片を石へ事前交換する操作は不要。

旧セーブ内のレアリティ別欠片は、上の対応に従って新しい欠片へ1対1で移行する。旧ユニークの欠片はVへ移行する。既存の完成した強化石はそのまま利用できる。瞬間英作文による完成石と粉の報酬もそのまま利用できる。
