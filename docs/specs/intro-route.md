# 入門ルート（実装PR・未マージ）

基準main: `ab58492c815b08ccbafdafdec6ebc642b028d709`。この文書の承認済み入門ルートは、旧「5ダンジョン先行版」の初期解放・森/洞窟の編成・新規遠征の帰還地点に優先する。旧森ボス等の受注済み契約の移行は未決定であり、本PRはその判断が済むまでマージしない。

## 新規進行

- 初期は `windward_plain`（風渡りの原）のみ。無料、3階各1戦、スライム1→2→3体、Lv1/1/2。季節置換・精鋭・賞金首・ボスなし。
- 原の踏破で `sunlit_forest` と `mossy_cave` を同時解放。出発画面の初期選択は未踏破の原→森→洞窟を優先し、原の周回を要求しない。
- 森はLv2/2/3の3戦。スクル2→スクル+毒キノコ→毒キノコ+スクル2。毒敵は最大1体、ボスなし。森踏破で石切り場（任意素材先）と湿原（毒対策ルート）。
- 洞窟はLv2/3/4の通常3戦とLv5 `goblin_boss`（岩窟のグラム）単独。ラットル2→ラットル+季節枠→ラットル2+季節枠。春の枠は花粉ムシ、夏はヒカリゴケの精、秋はキノコ兵、冬は洞窟コウモリ。ラットルはこの入門用固定編成では季節置換しない。洞窟踏破で砦。
- 原の地域係数0.70。実ゲーム算出後HPに原0.50、森0.58、洞窟通常0.67/ボス0.82を乗じ切り捨て、最低1。強さ・耐性・弱点・技・IDのモンスターマスターは変更しない。スライムの出現地域参照に原を追加するだけで総数1,024を維持。
- 原の報酬テーブルは同じ★1近場の森に合わせ、賞金首率のみ0。基準収入倍率0.65。新しい報酬機構は追加しない。洞窟の単独ボスは報酬配分の分母から取り巻き1体分を除き、一周の基準収入を維持する。保存済み旧経路は旧分母。
- 砦・湿原の敵数・戦闘数値は変更しない。他地域の敵計算にはHP補正を適用しない。

## 帰還・保存

公開6か所の**新規遠征**だけ固定帰還ポイントをなくす。最終戦に勝つと、ボスの有無によらず道具なしで帰還でき、帰還時に踏破を記録する。ボスなし最終戦から逃走した場合は同じ階で再挑戦できるが、踏破にも無料帰還にもならない。戦闘間の羽帰還は戦利品を持ち帰り、踏破には数えない。

新規ゲームだけ全員20AP、共有10,000G、帰還の羽1枚。既存AP・財布・アイテムは配り直さない。セーブ形式バージョンを増やさず、`game.introRouteVersion` と既得アクセス一覧、`run.introRouteVersion` と経路内の編成設定を追加する。

旧プレイヤーの初期3か所、発見記録、踏破済み公開先を再ロックしない。旧遠征の `run.route` を優先し、経路が欠ける旧v2レイアウトは `balance.dungeon.pre_intro_routes`、さらに古い経路は既存 `legacy_layout` で復元する。旧 `return_point` の保存からは羽0枚でも無料で戦利品を持ち帰れる。

全滅時の現行ルール（HP/石化、経験値/AP/図鑑の保持、戦利品と踏破の巻戻し）は変更しない。出題・戦闘・学習保存・6人編成も変更しない。

## 未決定の互換性（マージ阻害点）

旧森ボス `grove_guardian` のデータ・図鑑履歴・受注済み契約・保証金・既得報酬は削除しない。新規掲示には森/原のボス依頼・特別ボス依頼を出さない。

ただし**町で受注済み、未達成の旧森ボス依頼**は、新規の森から対象が消えるので、そのままでは達成できない。同じ問題は固定編成外の特定種討伐・賞金首・対象素材の旧契約にもあり得る。旧遠征中の契約は開始時の編成で継続できる。

推奨案は「達成手段が消える旧契約を持つ間だけ、明示した旧経路を選べるようにする」。契約・保証金・締切を維持でき、削除や報酬の自動加算が不要。ただし新規プレイヤー向けの森とは異なる例外になる。代案は契約を履歴へ保管し保証金を全額返還する方式（新たな精算規則が必要）。どちらも未承認なので未実装。ユーザー判断後に追加する。
