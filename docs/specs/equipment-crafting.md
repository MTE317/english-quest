昇級に必要なギルドポイント・モンスター素材・施設解放は [E〜Sランク正本](rank-promotion.md) を優先（未実装）。本書の旧昇格・旧ランクに関する記述は履歴。

[仕様索引](README.md) · [ゲームシステム](game-system.md) · [世界・ダンジョン](world-dungeon.md)

## 入手経路と役割

**確定。** 探索→討伐→素材入手→工房制作→ビルド調整→再挑戦を中心にする。

| 入手経路 | 役割 |
| --- | --- |
| ショップ | 基本装備を揃える |
| 通常ドロップ | ランダム効果を持つ装備を得る |
| 工房制作 | 狙うビルドに合う固定効果の装備を作る |
| 最奥ボス | 固有装備・素材を得る。踏破後も周回で再抽選 |
| セット・闘技場 | セット構成や闘技場装備を選択肢に加える |
| 宝箱・採集 | 周回時の装備・素材収集を補助する |

通常進行で必要な対策装備や素材には、その対策が必要なボスを倒す前の入手経路を用意する。素材奉納の鍵素材は [ジョブ解放](game-system.md) の確定条件に従う。

## エンチャントと現行データ

エンチャントはランダム付与と狙った固定効果の役割を維持する。既存の [付与効果](../../data/affixes.csv)、[等級](../../data/enchant_grades.csv)、[付与元](../../data/enchant_sources.csv) を参照する。個別化した付与値の最終バランスは実戦検証で調整する。

### 対象別エンチャント（実装）

制作した通常装備の2枠に、素材が許す系統と部位が許す系統の共通部分から効果を選んで付ける。新しい素材・専用素材は追加しない。ドロップ品のランダム効果と既存の固定効果は従来どおりとし、工房の数値だけ [エンチャント専用設定](../../data/enchant_overrides.csv) で上書きする。グレード1～12は最大値の0.7～1.8倍（装備Lvで伸びる能力値はさらに `1＋装備Lv÷12` 倍）。

| 系統 | 対象・部位 | グレード1→12の目安 |
| --- | --- | ---: |
| 属性攻撃強化 | 斬・突・打・炎・氷・風・土・雷・水・光・闇。武器／アクセサリー | 武器8.4→21.6％、装飾品5.6→14.4％ |
| 属性耐性 | 上記11属性。頭・体・腕／マント／アクセサリー | 既存の部位別数値 |
| 状態異常付与率 | `status_effects.csv` の20種類から一つ。武器／アクセサリー | 武器10.5→27％、装飾品8.8→22.5％ |
| 状態異常耐性 | 上記20種類から一つ。頭・体・腕／マント／アクセサリー | 頭・体・腕と装飾品14→36％、マント11.2→28.8％ |
| 状態異常中の敵への特効 | 20種類＋能力ダウンから一つ。武器／アクセサリー | 既存の部位別数値 |
| 継続ダメージ強化 | 毒・猛毒・火傷・出血から一つ。従来 `DOT_POWER` を許す部位 | 既存の部位別数値 |
| 種族特効 | 既存の18種族。武器 | 既存値 |

魔法8属性の素材は同じ属性の攻撃強化・耐性・武器への属性追加を選べる。属性タグが空または `none` の既存素材から物理3属性の攻撃強化・耐性を選べる。状態異常付与率・耐性・特効・継続ダメージを許す従来の素材からは、同じ素材で対象を自由に選べる。ボス素材は対応部位の全系統を選べる。全状態異常共通の `STATUS_RATE`・`STATUS_RES`・`DOT_POWER`・`VS_DEBUFFED` は新規エンチャント候補から除くが、既存装備の効果は引き続き機能する。

属性攻撃強化はその属性を含む通常攻撃・技能・魔法に適用し、複数属性なら装備の該当補正の最大値を一つだけ採用する。弱点倍率や既存の弱点強化は別途適用。状態異常付与率は該当する異常を付ける行動だけに適用し、敵の完全無効を突破しない。個別耐性は該当する異常の判定に加算し、既存の耐性上限100％を共有する。状態異常中の敵への特効は対象が複数かかれば従来の合計上限60％まで加算する。能力ダウンは状態異常20種とは別枠。
