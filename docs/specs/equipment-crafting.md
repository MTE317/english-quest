# 装備・素材・制作

昇級に必要なギルドポイント・モンスター素材・施設解放は [E〜Sランク正本](rank-promotion.md) を優先（未実装）。本書の旧昇格・旧ランクに関する記述は履歴。

## 入手経路と役割

**確定。** 探索→討伐→素材入手→工房制作→ビルド調整→再挑戦を中心にする。

| 入手経路 | 役割 |
| --- | --- |
| ショップ | 基本装備を揃える |
| 通常ドロップ | ランダム効果を持つ装備を得る |
| 工房制作 | 狙うビルドに合う固定効果の装備を作る |
| 最奥ボス | 固有装備・素材を得る。踏破後も周回で再抽選 |
| セット・闘技場 | セット構成や闘技場装備を選択肢に加える |
| 宝箱・採集 | 周回時の装備・素材収集を補助する |

通常進行で必要な対策装備や素材には、その対策が必要なボスを倒す前の入手経路を用意する。素材奉納の鍵素材は [ジョブ解放](game-system.md) の確定条件に従う。

## 装備の成長軸（実装）

**2026-11-27の実装。** 通常装備の基礎値は [★別基準表](../../data/equipment_tiers.csv) に置く。同じ★・武器種または防具種なら店売り・ドロップ・製作で共通の基礎値を使う。★の表は従来の同一★の低・高2系列の中間値から始めた暫定値で、戦闘検証後に調整する。

| 軸 | 改定後の役割 | 現行との差 |
| --- | --- | --- |
| 装備の★1〜12 | 武器・防具・マント・アクセサリーの基礎性能と入手・製作段階を決める | 現行の装備Lvによる基礎性能を★へ移す |
| レアリティ | 同じ★の基礎性能を少し上げ、天然効果の個数と天然・後付け効果の数値を決める | 現行は主に天然効果の個数を決める |
| 強化値+0〜+10 | プレイヤーが素材とゴールドを使って、その装備を育てる | 装備Lvに置き換わる数値ではない。★の基礎値に加わる別の成長軸 |
| 装備Lv | 使用・表示しない | キャラクターLv、英語教材の★、ギルドランクとも混同させない |

同じ★にあった2系列のIDと名前は、既存のレシピ参照と所持装備の保存IDを守るため残す。ゲーム内では装備Lvを表示・参照せず、2系列の性能は同じ。CSVの旧装備Lv列は既存のオフラインシミュレーター互換のために残すが、ゲーム処理には使わない。通常ドロップは地域の★に一致する装備から抽選する。店売りは対応★の店舗品を出す。専用レシピの素体IDも★で評価する。ユニークとセットは通常レアリティ倍率の対象外とする。

### レアリティ補正（実装値）

| レアリティ | 基礎性能倍率 | 天然効果の個数 | 天然効果・後付けエンチャントの数値倍率 |
| --- | ---: | ---: | ---: |
| コモン | 100% | 0 | 100% |
| アンコモン | 102% | 1 | 102% |
| レア | 104% | 2 | 104% |
| エピック | 107% | 3 | 106% |
| レジェンダリー | 110% | 4 | 108% |
| アーティファクト | 113% | 4 | 110% |
| オリジン | 116% | 5 | 112% |

基礎攻撃力・防御力は、まず★と装備種別で決め、その後に基礎性能倍率と強化倍率を各1回だけ適用する。天然効果や後付けエンチャントは、それぞれ効果の基準値を決めてから右端の倍率を**1回だけ**適用し、基礎性能倍率を重ねて掛けない。STRなど装備段階で伸びる効果は★別基準表の係数を使う。効果値は小数第一位へ丸め、装備基礎値は最終能力値の計算時に丸める。既存の効果別上限と同名効果の合算を維持する。

製作装備の現行の隠れた基礎性能約+15%（`quality`）は廃止する。製作装備はコモンの基礎性能を使い、レシピ固有効果と後付けエンチャントを強みとする。レアリティ補正をレシピ固有効果やセットボーナスへ自動適用しない。ユニーク・セット装備は通常の7段階レアリティとは別区分で、★基準の基礎性能を使う。現行の付与枠0と固有効果・分解処理を維持する。

瞬間英作文の1セットを完了すると、強化石とエンチャント素材を**両方同時に**得る。5問なら各1個、10問なら各2個、15問なら各3個の固定報酬とし、自己判定の正答率で個数を増減しない。素材の上位段階はギルドランクに連動して解放し、解放済みの低段階も選べるようにする方針。具体的な解放ランク、石と粉の名称・段階数、報酬対象となる復習の扱いは未確定。

強化の成功率は★ではなく**現在の強化値**で決める。失敗しても装備と強化値は失わない。現行の1段階につき基礎性能約5%増、鍛冶屋ランクによる+3〜+10の上限は数値調整まで暫定値とする。強化石の★帯別の段階、10欠片→同段階の石1個、分解で一段下の素材を得る方針は維持するが、各★の対応・数量・返却率は別途試算する。

通常ドロップ装備・店売り・製作装備は後付けエンチャント2枠。ユニーク・セット装備は0枠。枠1から順に付け、同じ枠への再付与はその枠だけ置き換える。ドロップの天然効果、製作の固定効果は残る。天然効果の振り直しは後付け枠を変更しない。

### 今後の数値検証

- ★別基礎値は旧2系列の中間値。序盤の店売りが強くなり、同じ★の高段階ドロップは弱くなる。実戦の勝率と製作価値を検証して基準表を調整する。
- 高レアは天然効果5個と基礎性能116%が同時に付く。6人編成での耐久・ダメージを検証し、レア～エピックでも攻略可能にする。
- 瞬間英作文の石・素材報酬と段階解放、強化石の★別素材設計、旧シミュレーターの数値式は別途実装・検証する。

## エンチャントと現行データ

素材と付与候補は [付与効果](../../data/affixes.csv)、[等級](../../data/enchant_grades.csv)、[付与元](../../data/enchant_sources.csv)、[専用数値](../../data/enchant_overrides.csv) で管理する。制作固有効果とドロップの天然効果を維持し、後付け枠だけを選んで更新する。

### 対象別エンチャント（実装）

通常装備（店売り・ドロップ・製作）の2枠に、素材が許す系統と部位が許す系統の共通部分から効果を選んで付ける。新しい素材・専用素材は追加しない。ドロップ品のランダム効果と既存の固定効果は従来どおりとし、工房の数値だけ [エンチャント専用設定](../../data/enchant_overrides.csv) で上書きする。グレード1～12は最大値の0.7～1.8倍（段階で伸びる能力値は★別基準表の係数をさらに掛ける）。レアリティの効果倍率は、天然効果を抽選した時と後付けエンチャント値を決める時にそれぞれ1回だけ掛ける。

| 系統 | 対象・部位 | グレード1→12の目安 |
| --- | --- | ---: |
| 属性攻撃強化 | 斬・突・打・炎・氷・風・土・雷・水・光・闇。武器／アクセサリー | 武器8.4→21.6％、装飾品5.6→14.4％ |
| 属性耐性 | 上記11属性。頭・体・腕／マント／アクセサリー | 既存の部位別数値 |
| 状態異常付与率 | `status_effects.csv` の20種類から一つ。武器／アクセサリー | 武器10.5→27％、装飾品8.8→22.5％ |
| 状態異常耐性 | 上記20種類から一つ。頭・体・腕／マント／アクセサリー | 頭・体・腕と装飾品14→36％、マント11.2→28.8％ |
| 状態異常中の敵への特効 | 20種類＋能力ダウンから一つ。武器／アクセサリー | 既存の部位別数値 |
| 継続ダメージ強化 | 毒・猛毒・火傷・出血から一つ。従来 `DOT_POWER` を許す部位 | 既存の部位別数値 |
| 種族特効 | 既存の18種族。武器 | 既存値 |

魔法8属性の素材は同じ属性の攻撃強化・耐性・武器への属性追加を選べる。属性タグが空または `none` の既存素材から物理3属性の攻撃強化・耐性を選べる。状態異常付与率・耐性・特効・継続ダメージを許す従来の素材からは、同じ素材で対象を自由に選べる。ボス素材は対応部位の全系統を選べる。全状態異常共通の `STATUS_RATE`・`STATUS_RES`・`DOT_POWER`・`VS_DEBUFFED` は新規エンチャント候補から除くが、既存装備の効果は引き続き機能する。

属性攻撃強化はその属性を含む通常攻撃・技能・魔法に適用し、複数属性なら装備の該当補正の最大値を一つだけ採用する。弱点倍率や既存の弱点強化は別途適用。状態異常付与率は該当する異常を付ける行動だけに適用し、敵の完全無効を突破しない。個別耐性は該当する異常の判定に加算し、既存の耐性上限100％を共有する。状態異常中の敵への特効は対象が複数かかれば従来の合計上限60％まで加算する。能力ダウンは状態異常20種とは別枠。
