# 装備・制作・エンチャント

[仕様索引](README.md) · [ゲームシステム](game-system.md)

## 装備の区分

装備の★1〜12は基礎性能・入手段階・工房で払うゴールドを決める。同じ★・装備種の店売りと通常ドロップは同じ基礎性能を持つ。+0〜+10の強化値は別軸である。

通常装備のレアリティはコモン～オリジン。制作装備とボス・賞金首の固有装備は、入手経路を別データに保ち、ゲーム内ではいずれも「ユニーク」と表示する。ユニークの基礎性能は★基準で、通常レアリティ倍率を掛けない。セット装備と2点・4点ボーナスは廃止する。

| 入手元・レアリティ | 入手時の効果数 | ①全再付与時の効果数 |
| --- | ---: | ---: |
| 店売り（コモン） | 0 | 0〜2 |
| 通常ドロップ・コモン | 0〜2 | 0〜2 |
| アンコモン | 1〜3 | 1〜3 |
| レア | 2〜4 | 2〜4 |
| エピック | 3〜5 | 3〜5 |
| レジェンダリー | 4〜6 | 4〜6 |
| アーティファクト | 4〜6 | 4〜6 |
| オリジン | 5〜7 | 5〜7 |
| ユニーク（制作・ボス） | 固有2〜4＋共通0〜2 | 固有2〜4＋共通0〜2 |

通常レアリティの基礎性能倍率・効果値倍率は [rarities.csv](../../data/rarities.csv) に従う。入手時の効果に別の「後付け枠」は足さない。通常ドロップの効果数は各レアリティの下限に0〜2個を加算して抽選する。

## ユニーク固有候補

各ユニークは固有候補を4種類持つ。ボス装備は [uniques.csv](../../data/uniques.csv) の候補を使う。制作装備は [recipes.csv](../../data/recipes.csv) の既存の効果を核とし、足りない候補を武器属性・状態異常・部位の役割に合う効果で補う。通常制作も部位に合う4候補を持つ。実際に付く固有効果を2〜4個、さらにその部位の共通効果を0〜2個抽選する。固有0個は発生せず、同じ効果を二重に付けない。

例：岩窟のグラムの拳は STR・会心率・MAG・経験値増加から2〜4個を抽選する。共通候補からSPDなどが別途0〜2個付く。装備名や制作武器の追加属性は残るが、候補のうち実際に付く効果は個体ごとに異なる。

数値がある固有候補は、元データの値の80〜120％を抽選する。元データは★に応じた値なので、★係数を重ねない。数値のない属性付与・致命傷耐えは数値再抽選の対象外。現行データの日本語別名は処理用の効果IDへ変換する。

## 工房の2操作

①全再付与は、今ある効果をすべて消し、効果数・種類・数値を再抽選する。任意のモンスター素材を1個追加でき、対応候補が存在すれば65％でその候補群、35％で部位の全候補群から選ぶ。対応候補でも狙いの1種類は確定しない。ユニークの固有候補は4種類の中から2〜4個を引き直す。

②数値再抽選は、装備に付いている数値効果1個を指定する。種類・効果の個数・固有／共通の由来は維持し、数値だけを同じ種類の範囲から抽選し直す。①②とも現在より弱くなる場合がある。数値のない効果は②で選べない。

どちらも [workshop-materials.js](../../game/js/workshop-materials.js) のエンチャント粉を10個使う。ゴールドは装備★に対応する [economy_by_rank.csv](../../data/economy_by_rank.csv) の制作費の2倍。追加素材を使う場合は1個消費する。

## 数値の決まり方

通常の共通効果は [affixes.csv](../../data/affixes.csv) の最小・最大値を使う。 [enchant_overrides.csv](../../data/enchant_overrides.csv) は個別属性・状態異常の効果上限を定義する。STRなど「装備段階で伸びる」効果は [equipment_tiers.csv](../../data/equipment_tiers.csv) の★係数を使い、通常レアリティの効果倍率を1回だけ掛ける。

工房の [enchant_grades.csv](../../data/enchant_grades.csv) の数値倍率は、操作時の施設Lvに応じて自動適用する。プレイヤーがグレードを選ぶ操作はない。Lv1は0.7倍、Lv4は1.0倍、Lv8は1.4倍、Lv11は1.8倍。制作時には当時の施設Lvを適用し、ボスドロップ時には施設倍率を掛けない。工房のLv上昇で所持装備の値は自動更新されず、再抽選時に新Lvを反映する。

## 強化と素材

強化石I〜Vは装備★ではなく、上げる強化値で決まる。+0〜+3はIを各3個、+3〜+5はIIを各5個、+5〜+7はIIIを各5個、+7〜+9はIVを各10個、+9〜+10はVを10個使う。成功率と施設による上限は [enhance_rates.csv](../../data/enhance_rates.csv)・[facility_ranks.csv](../../data/facility_ranks.csv) に従う。失敗しても装備と強化値は維持し、指定の石・ゴールドを消費する。

瞬間英作文の5・10・15問セットを最後まで完了すると、選んだ段階の強化石をそれぞれ1・2・3個、共通のエンチャント粉を**どのセットも1個**得る。通常の瞬間英作文とチャンク集中に適用し、単語のみ・復習・途中終了では得られない。

武器・防具・アクセサリーの分解では、レアリティに対応する**強化石I〜Vの欠片を1個**得る。完成石Iや旧「レアリティ別の欠片」は確定付与しない。欠片3個は対応する完成石1個分として強化に使え、完成石との併用もできる。固有ユニーク装備は★に応じた欠片を返す。対応表と旧セーブ移行は[強化石の欠片](stone-fragments.md)を参照。

分解時に付いているエンチャント効果の数が0個なら粉0個、1～2個なら粉1個、3～4個なら粉2個、5個以上なら粉3個を得る。固有効果と共通効果は同じく1個と数える。装備★・レアリティ・強化値による粉の追加補正はない。
