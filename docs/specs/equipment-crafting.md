## 入手経路と役割

**確定。** 探索→討伐→素材入手→工房制作→ビルド調整→再挑戦を中心にする。

| 入手経路 | 役割 |
| --- | --- |
| ショップ | 基本装備を揃える |
| 通常ドロップ | ランダム効果を持つ装備を得る |
| 工房制作 | 狙うビルドに合う固定効果の装備を作る |
| 最奥ボス | 固有装備・素材を得る。踏破後も周回で再抽選 |
| セット・闘技場 | セット構成や闘技場装備を選択肢に加える |
| 宝箱・採集 | 周回時の装備・素材収集を補助する |

通常進行で必要な対策装備や素材には、その対策が必要なボスを倒す前の入手経路を用意する。素材奉納の鍵素材は [ジョブ解放](game-system.md) の確定条件に従う。

## 装備の成長軸（改定方針・コード未実装）

**2026-11-27に合意した設計。** この節は装備Lvの廃止、★・レアリティ・強化値への整理、製作装備の隠れた基礎性能補正の廃止を定める。現行のCSV・戦闘計算・画面はまだ旧仕様であり、「実装済み」として扱わない。新しい数値を決めるまでは現行ゲームの挙動が優先する。

| 軸 | 改定後の役割 | 現行との差 |
| --- | --- | --- |
| 装備の★1〜12 | 武器・防具・マント・アクセサリーの基礎性能と入手・製作段階を決める | 現行の装備Lvによる基礎性能を★へ移す |
| レアリティ | 同じ★の基礎性能を少し上げ、天然効果の個数と天然・後付け効果の数値を決める | 現行は主に天然効果の個数を決める |
| 強化値+0〜+10 | プレイヤーが素材とゴールドを使って、その装備を育てる | 装備Lvに置き換わる数値ではない。★の基礎値に加わる別の成長軸 |
| 装備Lv | 使用・表示しない | キャラクターLv、英語教材の★、ギルドランクとも混同させない |

同じ★・同じ武器種や防具種なら、店売り・通常ドロップ・製作装備の**補正前の基礎性能**を共通にする。武器種の倍率、防具重量、職業適性など、装備の役割による違いは維持する。現在の「同一★に低い装備Lvと高い装備Lvの2系列を置く」区別は撤廃し、ドロップは装備Lvの範囲でなく★と入手先で抽選する。現在の★1〜12と通常装備720件を新しい装備定義へどう整理するか、価格・ドロップ・製作レシピ・既存所持品の扱いは実装前に決める。

### レアリティ補正（採用する設計値）

| レアリティ | 基礎性能倍率 | 天然効果の個数 | 天然効果・後付けエンチャントの数値倍率 |
| --- | ---: | ---: | ---: |
| コモン | 100% | 0 | 100% |
| アンコモン | 102% | 1 | 102% |
| レア | 104% | 2 | 104% |
| エピック | 107% | 3 | 106% |
| レジェンダリー | 110% | 4 | 108% |
| アーティファクト | 113% | 4 | 110% |
| オリジン | 116% | 5 | 112% |

基礎攻撃力・防御力は、まず★と装備種別で決め、その後に基礎性能倍率と強化倍率を各1回だけ適用する。天然効果や後付けエンチャントは、それぞれ効果の基準値を決めてから右端の倍率を**1回だけ**適用し、基礎性能倍率を重ねて掛けない。STRなどの固定値が現行の装備Lvに応じて増える処理は★基準へ再設計する。割合効果の上限、同名効果の重複、丸め方は効果別に検証する。

製作装備の現行の隠れた基礎性能約+15%（`quality`）は廃止する。製作装備はコモンの基礎性能を使い、レシピ固有効果と後付けエンチャントを強みとする。レアリティ補正をレシピ固有効果やセットボーナスへ自動適用しない。ユニーク・セット装備は通常の7段階レアリティとは別区分であり、固有品の基礎性能・付与枠・分解結果は実装設計時に個別確認する。

瞬間英作文の1セットを完了すると、強化石とエンチャント素材を**両方同時に**得る。5問なら各1個、10問なら各2個、15問なら各3個の固定報酬とし、自己判定の正答率で個数を増減しない。素材の上位段階はギルドランクに連動して解放し、解放済みの低段階も選べるようにする方針。具体的な解放ランク、石と粉の名称・段階数、報酬対象となる復習の扱いは未確定。

強化の成功率は★ではなく**現在の強化値**で決める。失敗しても装備と強化値は失わない。現行の1段階につき基礎性能約5%増、鍛冶屋ランクによる+3〜+10の上限は数値調整まで暫定値とする。強化石の★帯別の段階、10欠片→同段階の石1個、分解で一段下の素材を得る方針は維持するが、各★の対応・数量・返却率は別途試算する。

後付けエンチャントを通常ドロップ装備にも開放する方針。現行の製作装備2枠、通常ドロップ装備0枠、ユニーク・セット0枠は**現行挙動**であり、改定後の通常装備・固有装備の枠数は未確定。エンチャントの付与・種類と数値の再抽選は、天然効果の振り直しやレシピ固有効果と別に扱う。素材や付与効果の詳細はエンチャント改定仕様との整合を取ってから確定する。

### 実装前に検証すること

- ★ごとの新しい基礎攻撃力・防御力、店売り・ドロップの性能差の消失による序盤難易度、製作品の+15%撤廃後の価値。
- 最高レアは天然効果5個と基礎性能116%が同時に付くため、6人編成のダメージ・耐久・割合効果の上限。レア〜エピックでも攻略可能であること。
- 装備Lvを参照するドロップ候補、武器・防具・魔法補助・固定ダメージ、効果の抽選、エンチャント、ショップ価格・売却価格、強化費用、レシピと工房上限、UI、シミュレーションの置換。
- 高レアの出現率と狙った武器種・効果の組み合わせは、装備Lvを消しても入手難度が残る。最高レアを進行の必須条件にしない。
