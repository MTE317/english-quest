# 5ダンジョン先行版（2026-11-24）

> **履歴資料。** このページの初期3か所公開と5か所限定は現行の入場条件ではない。現在は[風渡りの原からの入門ルート](intro-route.md)と[風鳴りの峡谷](howling-canyon-public.md)を参照。ランク・施設は[E〜Sランク](rank-promotion.md)と[11段階の施設投資](town-facilities-11.md)が現行仕様。

世界地図の地域ノード・接続線を撤廃し、既存コンテンツを活用した5か所のプレイ検証を行うための実装方針。

- 旧14地域の配置・地域番号・接続線は表示にも入場判定にも用いない。
- 冒険者ランク・教材の★は、この5か所への入場を制限しない。
- 入場できる5か所を一覧カードから直接選択する。未発見の行き先の名前は公開しない。
- ギルドの未受注掲示は現在公開されているダンジョンからのみ生成する。従前に受注済みの依頼や保証金は維持する。
- 既存の60ダンジョン、1,024モンスター、ボス、報酬、レシピ、進行中の遠征の保存データは削除・変更しない。
- 既存の探索イベントで将来の場所を発見しても、先行版の非公開ダンジョンへの入場はできない。
- 受注済みの旧特殊探索は、過去の条件を満たしていれば報告できる。新規受注は現行公開範囲のみ。
- 24地域・68ダンジョンの配分と正式な世界解放グラフは、先行版のプレイ検証後に再設計する。
