## 地域別ギルド掲示板

**確定。** 掲示板を一本化し、地域を選択して★難度で絞る。討伐・採集・ボス・賞金首を扱う。地域ごとの達成可能な通常依頼は3〜6件が目標。同時受注数に上限はなく、同じ内容の依頼は重複受注できない。連続クエストは廃止し、進行条件は特殊探索（SQ-*）・踏破履歴・ギルドポイント・昇格試験で管理する。特殊探索は一度限り、通常依頼は繰り返し受注できる。特殊探索 `SQ-*` は地域や前提条件で解放し、通常枠（最大6）と別の固定枠に同じUIで掲示する。

現在入場可能な行き先、当季に出る敵・入手できる素材から候補を生成する。特定個体に限定する必要のない討伐は地域・ダンジョン単位を基本とし、候補枯れを抑える。候補が0件になる場合の扱いは検証課題。

依頼ごとに過去の踏破・素材発見などの既存実績を遡及評価できる。「受注後に5体討伐」や納品は受注後の新規達成を数える。達成日時を記録し、遠征を巻き戻す場合は遠征中の達成も取り消す。時刻の境界と旧セーブ移行は要検証。

**実装状況。** 現行地図の地域と入場可能な★で掲示を切り替えられる。通常掲示は最大6件、同時受注数に上限はない。連続依頼の専用タブ・ステップ進行・次段の再受注は廃止。旧セーブの履歴はアーカイブし、未受領の完了分と探索・討伐で進めた段階を一度だけ精算する。現行の依頼ポイントは対象★と依頼種類で決まり、格下の★を選んでも減点・0点化しない。旧セーブの移行時の精算記録と、新規依頼のポイント計算は区別する。特殊探索の第1章は2話。安全に帰還して記録を持ち帰ると通常掲示とは別枠に現れ、受注後の踏破と各話の条件を満たすと個別報酬を一度受け取れる。

## 賞金首

**確定。** 総数48体。最奥ボスとは別枠で、遭遇した場合は道中の通常敵1体を置換し、戦闘数を増やさない。固有装備と高額報酬があり、遭遇保証も依頼期限も設けない。出発時に抽選し、その遠征の編成を固定する。

| 要素 | 仮仕様・仮数値 |
| --- | --- |
| 依頼受注中の基準 | 1遠征につき40% |
| 未受注の基準 | ダンジョンごとの通常確率 |
| 道具・パッシブ・装備 | 順に+15、+10、+5百分率ポイント。同系補正はパーティーで最大1つ採用 |
| 上限 | 80% |
| 賞金首の保証金 | 現行の報酬10%を暫定維持。報告で全額、自主放棄で80%返還 |

受注中40%と各補正・上限を実装。おびき寄せ香は出発時に任意で1個消費し、全滅時も返却されない。

## 遠征費と旧会費

**確定。** ギルド月会費、会費滞納、滞納利息を廃止し、ダンジョンごとの遠征費へ移行する。ゲーム内日数・季節、銀行の通常ローンとその利息、宿代、工房費用は維持する。旧セーブの会費滞納は移行時に清算する方向。通常ローンと混同しない清算処理は要検証。

**実装状況。** 遠征費は想定1周ゴールド収入×8%を整数に四捨五入する。初期1ダンジョンは恒久無料。費用は出発時に払い、踏破・途中帰還で確定し、全滅で返還する。旧会費滞納だけを移行時に清算し、銀行融資を維持する。

## 期限と保証金

通常の討伐・採集・ボス、ストーリー、特殊探索は期限も保証金も設けない。賞金首は上記の無期限・保証金方式。期限を設けるのは高報酬の特別依頼のみ。

**仮仕様を実装。** 通常掲示とは別枠で、最奥ボス討伐の特別依頼を掲示する。対象の遠征日数1／2／3日以上に対し、期限8／10／12ゲーム内日。受注時に基本報酬の10%を預ける。期限内の達成で保証金返還とゴールド報酬30%増。期限超過後も依頼は継続し、達成時は通常報酬で保証金は没収。判定は討伐日を使い、報告日は問わない。
