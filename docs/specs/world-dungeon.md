## 発見・入場・踏破

**確定。** 初期表示は3地域。未発見地域は表示せず、発見に応じて霧が晴れ、ノードが増える。発見済み、挑戦可能、踏破済みを区別する。発見だけで入場を許可せず、入場は探索、クエスト、解放フラグ等で判定する。冒険者ランクと教材難度の入口制限は撤廃する方針。強敵に遭遇して退却し、耐性・編成・装備を整えて再挑戦する遊びを重視する。

地図の地理的接続と入場条件を分ける。遠隔解放を許し、東西の並びを進行順の前提にしない。設計規模は24地域、常設56＋独立した季節12＝68ダンジョン、終着6＋任意の隠し1。終着や隠し目的地の詳細は中立IDで管理する。

**保留。** 具体的な地域配置・経路・正式な解放グラフ・季節ダンジョンの詳細はシミュレーション後に確定する。v3は構想。旧v2の14地域は暫定。

**実装状況。** [main のダンジョン](../../data/dungeons.csv) は60件。[PR #44](https://github.com/MTE317/english-quest/pull/44) は初期3地域、霧、段階表示、遠隔発見を含む暫定14地域の実装。既存のランク・経路条件を残している。24地域・68ダンジョンへの移行と新しい入場制御は未実装。

## ダンジョンと奥のボス

**確定。** 新規遠征の内部経路は一本道。基本2／3／6戦で、最終戦は必ずボス。踏破済みでも再遠征のたびに最奥ボスと戦え、素材・固有装備を再抽選できる。途中帰還とボス撃破後の帰還を用意する。ボスのいない育成探索、分岐通路、任意で強敵に挑むイベントは廃止する。賞金首は道中の通常敵枠を置換する別の仕組み。

## 探索イベント

| 種類 | 処理 |
| --- | --- |
| 宝箱 | 初回固定の宝箱と周回で抽選する宝箱 |
| 採集 | 遠征先に対応する素材を得る |
| 休憩 | HP・MPを一部回復する |
| 隠し通路の発見 | 発見情報を得る。経路は一本道のまま |
| 調査地点 | クエスト進捗や解放フラグを得る |
| 帰還地点 | 町へ戻るか先へ進むかを選ぶ |

通常枠の発生と内訳は**仮数値**。2戦は1枠50%、3戦は1枠80%、6戦は独立2枠各80%。発生した枠の内訳は宝箱45%、採集40%、休憩15%。初回固定箱と発見・調査・帰還などの固定地点は通常枠の外。取得や回復は自動処理してテンポを優先する。

| 結果 | 確定・巻き戻し |
| --- | --- |
| 途中帰還 | 獲得物と途中到達の固定記録を確定 |
| 最奥ボス撃破後に帰還 | 獲得物と固定記録に加えて踏破を確定 |
| 全滅 | 遠征前のスナップショットへ戻す。学習記録・詠唱・JPを維持 |

**保留。** 全滅で地図の発見記録だけ残す案。**PR実装・未マージ。** [PR #45 の探索仕様](https://github.com/MTE317/english-quest/blob/2516ec1c37307f15b1faf41095b8aaaf6923da44/docs/dungeon-exploration.md) では発見も安全な帰還時に確定する。現行60件での2／3／6戦、ボス周回と6種のイベントを扱い、開始済み旧育成遠征は保存済み経路で完走できる。新規発見ゲートの正式配置や特殊クエスト本編は未実装。
