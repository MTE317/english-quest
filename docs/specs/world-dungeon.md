## 発見・入場・踏破

**現行の先行公開。** 初期は風渡りの原だけを表示し、踏破で森と洞窟、その先の石切り場・湿原・砦を段階的に公開する。砦または湿原を踏破すると風鳴りの峡谷が現れる。未公開の行き先の名前は表示しない。冒険者ランクと教材難度は入場制限に用いない。強敵に遭遇して退却し、耐性・編成・装備を整えて再挑戦する遊びを重視する。詳しくは[入門ルート](intro-route.md)と[峡谷](howling-canyon-public.md)を参照。

**将来構想。** 地図の地理的接続と入場条件を分け、遠隔解放を許す。設計規模は24地域、常設56＋独立した季節12＝68ダンジョン、終着6＋任意の隠し1。終着や隠し目的地の詳細は中立IDで管理する。

**保留。** 具体的な地域配置・経路・正式な解放グラフ・季節ダンジョンの詳細はシミュレーション後に確定する。v3は構想。旧v2の14地域は暫定。

**実装状況。** [ダンジョンの登録データ](../../data/dungeons.csv)は60件だが、先行版では上記の入門6か所と峡谷を段階公開している。旧14地域のノード・接続線は現行の表示や入場判定に用いない。遠征では行き先の★や冒険者ランクに関係なく、出題項目が入った教材を選べる。24地域・68ダンジョンへの移行は未実装。

## ダンジョンと奥のボス

**現行と将来の違い。** 新規遠征の経路は一本道。風渡りの原・木漏れ日の森など入門先にはボスなしの最終戦があり、勝利後は無料で帰還して踏破できる。洞窟と峡谷などには最奥ボスがいる。将来の地域では基本2／3／6戦・最終戦ボスを設計目標とする。踏破済みのボスも再遠征で戦える。賞金首は道中の通常敵枠を置換する。

## 探索イベント

| 種類 | 処理 |
| --- | --- |
| 宝箱 | 初回固定の宝箱と周回で抽選する宝箱 |
| 採集 | 遠征先に対応する素材を得る |
| 休憩 | HP・MPを一部回復する |
| 隠し通路の発見 | 発見情報を得る。経路は一本道のまま |
| 調査地点 | クエスト進捗や解放フラグを得る |
| 帰還地点 | 町へ戻るか先へ進むかを選ぶ |

通常枠の発生と内訳は**仮数値**。2戦は1枠50%、3戦は1枠80%、6戦は独立2枠各80%。発生した枠の内訳は宝箱45%、採集40%、休憩15%。初回固定箱と発見・調査・帰還などの固定地点は通常枠の外。取得や回復は自動処理してテンポを優先する。

| 結果 | 確定・巻き戻し |
| --- | --- |
| 途中帰還 | 獲得物と途中到達の固定記録を確定 |
| 最奥ボス撃破後に帰還 | 獲得物と固定記録に加えて踏破を確定 |
| 全滅 | 全員が死亡または石化した時点で、全滅状態のまま町へ帰還して即時保存。戦利品・取得ゴールドを失い、消費した道具は返却しない。経験値・AP・図鑑・学習記録・詠唱・旧セーブのJPは維持。日数・依頼進捗・発見・踏破は出発前に戻る |

発見も安全な帰還時に確定し、全滅では出発前へ戻す。全滅時に発見記録だけを残す案は未採用。現在の先行公開以外の正式な解放グラフと季節ダンジョンの配置は未確定。
