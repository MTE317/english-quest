# モンスターの固定能力とエリート

2026-11-28。敵設計の①「敵ごとの固定Lv・能力」を実装。②A〜Mの出現候補の再選定、③体数・編成・出現率によるダンジョン難度調整は後続。

## 固定能力

正本は [monster_stats.csv](../../data/monster_stats.csv)。既存のモンスター1024種すべてに1つずつ、固定Lv・HP・MP・攻撃・魔力・防御・魔防・素早さを設定する。属性・耐性・技・素材などは従来のモンスターマスターを使用する。別Lvのスライムなどの新IDは追加しない。

敵を生成するとき、ダンジョンの基準Lv・★・enemy_mul・HP補正は固定能力に掛けない。同じ通常モンスターなら場所・階・季節によって基本能力は変わらない。敵Lvの個体差抽選も行わない。エリートだけは後述の明示的な能力補正を加える。

地域1の15種は個別に暫定Lvを置いた。残る1009種の初期値は、既存の所属地域と★に対応する階層Lvの中央値を基に一度だけ計算して保存した暫定値（review=provisional）。現時点で全1024種のバランス調整が完了した意味ではない。

正確な日本語名・能力一覧は [地域1の固定能力](../monster-stats-region1.md)。同Lvでも能力・技・耐性が違うため、Lvだけで難しさが決まるものではない。

ダンジョンの既存levelは設計上の難度の目安として残し、敵のLvには使わない。出現候補は今回は変更しないため、A・E・Hなど同じ候補・体数の場所は同程度の強さになる。地域ごとの区別は②③で作る。

## エリート

正本は [monster_elites.json](../../data/monster_elites.json)。通常種の一部だけを対象にする。

| 項目 | 初期設定 |
| --- | --- |
| 対象 | スライム、ゴブリン、ワーグの仔、砦の野盗の4種 |
| 名前・Lv | 通常と同じ。別名や別Lvのモンスターは作らない |
| 表示 | 戦闘画面に◆。同種複数体を区別するA/Bは通常どおり付ける |
| 出現 | 対象の通常敵が選ばれたとき6%でエリート化 |
| 上限 | 1戦1体、1回の連続遠征で合計1体。ダンジョン移動ではリセットしない |
| 除外 | ボス戦、賞金首との同時出現、対象外の種 |
| HP | 通常の1.5倍 |
| MP・攻撃・魔力・防御・魔防 | 通常の1.2倍 |
| 素早さ | 通常の1.1倍 |
| レア素材 | その敵のレア素材ドロップ率を3倍（100%まで） |
| レア以上の装備 | その戦闘で装備が落ちた場合、レア以上の抽選重みを2倍 |
| その他の報酬 | 通常素材率、装備そのものの落ちる確率、経験値・AP・ゴールドには新たな加算なし |

「抽選重み2倍」は最終的な確率が2倍になる意味ではない。コモン・アンコモンと合わせて再正規化される。装備は戦闘単位の抽選なので、エリートを含む戦闘の装備抽選に適用し、複数体による倍率の重複はしない。ボス固有装備のドロップ率は変更しない。

旧来の「巨大な」「猛る」などの冠付き敵は、新しい固定マスターの敵生成では使用しない。進行中の旧セーブに保存されている敵の名前・能力・報酬は、その戦闘の終了まで保持する。

## 保存・図鑑・調整

戦闘開始時に生成した敵をそのまま保存する。読み直しで能力やエリート判定を抽選し直さない。図鑑は同じ種として遭遇・討伐を合算し、能力欄には通常個体の固定値を載せる。最初にエリートへ遭遇しても通常個体の能力に混ぜない。既存の情報開示条件は維持する。

新しい値の調整はmonster_stats.csvを直接変更する。初回値を作った scripts/build-monster-stats.mjs は移行用であり、通常運用では再生成しない。--overwrite は手動調整値も上書きする。

季節による強さの違いは、今後、出現候補・編成・出現率で表現する。今回、新地域の季節別編成はまだ追加していない。
