# 学習・冒険者ランク（2026-11-24 学習施設統合版）

[仕様索引](README.md) · [ゲームシステム](game-system.md)

## 基本教材
[教材基本版v1.0](../../data/learning/v1/README.md)（単語・熟語1,600、瞬間英作文1,183、チャンク215、7メイン・60サブ）を学習基盤とする。
00は共通IDで集計する重要コレクション。難度★は学習の表示情報であり、冒険先の入場制限ではない。
英会話の補助ツールのため、AI会話・模擬会話の採点は設けない。

## 学習施設
- **ダンジョン**：単語・熟語の英→日4択（設定で逆方向も選択可能）。XP・AP・装備・素材・Gは冒険で獲得。
- **訓練場**：単語・熟語の新規学習、瞬間英作文、共通チャンクの例文反復、両方のSRS復習、苦手練習。5/10/15問。
  - 6人全員にごく少量のXP/AP（冒険基準の約10%、仮数値）。小数繰越し、整数XP/APへ換算。
  - 項目ごとの報酬は1日1回まで。期限が来た復習の正答は1.2倍。
  - 英作文の○△×自己判定で基本報酬に差を付けない。間違えた問題も再練習可能。
  - 戦闘なし、ゲーム内日数は進まず、素材・お金・装備も出ない。
- **試験の間**：通常は単語20問・英作文10問を別々に採点し、それぞれ80%以上で合格。
  - 英作文は○1点・△0.5点・×0点の自己評価。合格履歴は分野別に保存。
  - S最終はボスと単語30問・英作文20問（仮値）。試験でXP/AP/素材/装備は付けない。
- **学習統計**：現在習得・累積で一度でも習得した固有ID数、復習期限、カテゴリー別進捗、日別回答、チャンク定着。

資料室と石碑の間、独立した詠唱の間は廃止。確認テストの代わりに試験の間で二分野を評価する。

## RPG成長と転職
- 転職は**無料**。解放済みジョブには何度でも転職可能。
- ジョブ解放条件、覚えたスキル、ジョブ別APは維持する。
- 転職通貨JP、ルーンストーンの能力補正は使用しない。
- データ変更による過去のセーブ移行を目的としない基本版v1.0の開発構成。
