# ワールドストーンと連続攻略

更新：2026-11-28。新規遠征の現行仕様。旧経路の途中セーブは帰還まで旧処理を継続する。

[仕様索引](README.md) · [設定データ](../../data/world_routes.json) · [検証](../../game/verification/world-journey/README.md)

## 基本動作

- 町の「始まりのワールドストーン」から A・E・H・M の4入口を選ぶ。
- A〜Mはすべて3戦。今後は各ノードの `battles` 設定で個別に延長する。
- 最終戦に勝利し、拾った物を整理した後に左・直進・右を選ぶ。途中の戦闘では道を選ばない。
- 出口3択は勝利見出しの直後、報酬・仲間の状態より上に表示。再読み込み後も上部に表示する。
- 3択の行き先はその地点のその方向を一度選ぶまで「？？？」。未選択の出口では町への帰還案内も隠す。季節・閉鎖表示は残す。同じ行き先でも方向ごとに判定し、選択済みの記録は帰還・全滅・再読み込み後も有効。
- 行き先の敵Lvは入口・出発欄・出口3択・地図に表示しない。出発欄の「3戦を終えたら、次の道を選びます。」の案内も表示しない。入口の戦闘数表示は残し、敵の強さや戦闘数の設定は変更しない。
- 以前のダンジョンへ戻る場合も最初から再挑戦する。
- HP・MP・状態異常・消費済み道具・未確定の戦利品と取得金・教材の出題履歴を引き継ぐ。移動による回復はない。既存技能の戦闘後回復は有効。
- 出発時に1日進め、連続攻略中は日付を進めない。季節は出発後の日付で固定。遠征費は暫定0G。
- 発見・踏破済みでも途中のダンジョンに町から直接入れない。

## 帰還と記録

| 操作・結果 | 動作 |
| --- | --- |
| 町への出口 | 道具不要。「町に到着した。」と表示して帰還 |
| ワールドストーン到着 | ワープを恒久解放し、必ず町へ帰還。到着・解放を表示 |
| 途中帰還 | 戦闘外で既存の帰還の羽を消費。回復道具も戦闘外で使える |
| 安全な帰還 | 遠征全体の戦利品・取得金・依頼進捗・各ダンジョンの踏破回数を確定 |
| 全滅 | 死亡・石化したまま町へ。遠征全体の未確定の戦利品・取得金を失う。消費した道具は返さない |
| 全滅でも残すもの | 地図の発見・入口到達・出口発見・道の通過、既存仕様の経験値・AP・図鑑・学習記録 |
| 全滅で戻すもの | 従来のスナップショットに基づく日数・依頼進捗・未確定の踏破回数。地図記録とは別管理 |

次のダンジョンへ移るときに全滅復元用スナップショットを作り直さない。AからGまで進んで全滅した場合、出発以来の未確定戦利品を失う。

## 地図・季節・条件

- 初期表示は始まりのワールドストーンと4入口。クリア時に出口と隣接地点を発見する。
- 出口から存在を知った石は未到達。実際に到着するまでワープを解放しない。
- 出口単位で通過済み・未通過・閉鎖中を保存し、地図と一覧に表示。同じ町につながる直進と右も別記録。
- Iの右は春以外「春のみ・閉鎖中」で選択不可。到着済みの石4は他季節でも選択可能。
- 条件付き出口は `clears`（踏破ID）、`flags`、`quests`（報告済み依頼ID）を設定可能。全条件のAND判定で達成順を問わない。今回の地域1には季節条件以外は配置しない。
- 石2〜4は解放・選択まで実装。以降の地域の入口や接続は未配置で「この地域の続きは準備中です」と表示する。

## 敵とイベント

既存の敵・報酬を再利用し、通常戦は指定した2種から毎回1〜2体を抽選する。G・Kの最終戦はボス1体。

| A・E・H | slime / nut_squirrel | なし |
| B | cave_rat / slime | なし |
| C | skeleton / fort_bandit | なし |
| D・I | goblin / wolf_pup | なし |
| F | marsh_frog / mud_slime | なし |
| J | marsh_frog / wandering_armor | なし |
| G | fort_bandit / stone_statue | stone_giant |

敵数、HP補正、★、ドロップ・収入の参照元は設定データを正とする。連続9〜12戦の消耗・収入バランスは未確定。機能テストを難度調整の完了とは扱わない。

新経路では宝箱・採集・休憩・隠し通路・調査地点・途中の無料帰還地点・賞金首置換を生成しない。戦闘ドロップ・ボス・戦闘後回復技能は残す。旧経路のイベント処理は途中セーブ互換のため残す。

既存の逃走・逃走技能に加えて煙玉を追加。逃走可能な戦闘では確実に離脱し、逃走不能なら使用不可・消費なし。道具屋では200G。途中戦から逃げると次の戦闘へ進むが、最終戦は倒すまで踏破できない。

帰還魔法の新規スキル割り当て、季節ごとの個別敵強化設定、地域別掲示板UIは今回追加していない。

## 既存セーブ

- 町にいるセーブは新地図を初期化。旧踏破履歴を保存するが、新しい石を自動で全解放しない。
- 旧ダンジョンの進行中セーブは旧経路を維持し、帰還・全滅後の正規化で新地図に移る。
- 未完了の通常依頼は対象の敵・素材が出る新ダンジョンへ対応付けて進捗を維持。対応不能な未完了依頼は記録を保存して終了し、支払済み保証金を返す。完了済み依頼は報告可能。
- 旧探索イベントに依存する新規ストーリー依頼は出さない。既に達成済みで受注中の旧依頼は報告可能。旧保存データ自体は消さない。
- D昇格用の野盗素材はC・Gで入手可能。素材試験の案内も新地図に合わせる。
