# テストプレイを踏まえた難度・成長・情報開示の調整

2026-11-28。「敵が少し弱い」「レベル上昇が早い」「季節の敵を優先したい」「HP・MPが初回から見える」というフィードバックへの暫定調整。

| 項目 | 変更 |
| --- | --- |
| 地域1の39種（ボスを含む） | 固定HPを10%、攻撃・魔力を15%増加。Lv・MP・防御・魔防・素早さ・技・報酬は維持 |
| 必要経験値 | 次Lvまで round(25 × Lv^1.5) → round(37.5 × Lv^1.5)。戦闘と鍛錬に共通 |
| 鍛錬 | 必要経験値増加で最低報酬が自動的に増えないよう、下限比率を0.001から0.001/1.5へ補正。最低獲得XPは従来とほぼ同じ。通常の報酬計算・AP・日内制限は維持 |
| 季節限定種 | 該当季節の出現重みを3倍。季節外は出現なし。例：春のAの花粉ムシは1体目15%→約34.6%、夏のKの雷鳥は約3.1%→約8.7% |
| 強敵・回復役 | Lv11〜12の通常敵は単独、回復役1戦1体、エリートの既存上限を維持 |

Lv1→2の必要XPは25→38、Lv2→3は71→106、Lv5→6は280→419。既存の仲間のLvと保持XPはそのまま。既に得たLvを下げたり、XPを没収したりしない。

固定能力の正本は monster_stats.csv。今回強化するのは地域1の39種で、他地域の暫定985種は対象外。エリートは変更後の固定能力へ既存倍率を掛ける。進行中の敵は保存済み能力を維持し、次の戦闘から新しい能力を使う。

## 図鑑と戦闘表示

| 情報 | 通常敵 | ボス |
| --- | ---: | ---: |
| HP数値・HPバー | 1体討伐 | 1体討伐 |
| MP数値・MPバー | 20体討伐 | 4体討伐 |
| 種族 | 2体討伐 | 1体討伐 |

既存の図鑑開示条件を変更せず、戦闘画面の敵表示・敵の詳細ダイアログ・読み上げラベルにも適用する。未判明のHP・MPは数値もバーもDOMへ出さない。MPは「HP以外の能力」と同じ条件。属性スキャンはHP・MPの開示条件を解除しない。

討伐記録は既存どおり戦闘終了時に反映し、その記録に従って次の戦闘で表示する。通常種と同名のエリートは討伐記録を共有する。味方のHP・MP表示は維持する。ダメージ・回復量の戦闘ログは従来どおり表示する。

新世界の図鑑一覧もA〜Mに配置した39種を対象とし、知恵のフクロウなど追加配置された種を閲覧できるようにする。旧世界データだけを使う互換処理では従来の一覧を使う。

## 確認

playtest-balance.test.js で開示境界、エリートとの共有、固定能力、成長速度、鍛錬のXP/AP維持、季節種の増加を検証する。verify-monster-visibility.cjs で初回・HP開示後・MP開示前後の敵表示、詳細、読み上げラベル、保存再開を確認する。

戦闘時間・連続攻略の消耗感は引き続きプレイテストで調整する。上記の変更量は最終値ではない。
