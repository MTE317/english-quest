# 地域1のモンスターの技

2026-11-28。地域1に配置した39種に適用する。種族・弱点・耐性は既存の monsters.csv、固定Lv・能力は monster_stats.csv、行動は monster_skills.json を正本とする。[39種の一覧](../monster-actions-region1.md)、[配置一覧](../region1-encounters.md)。

## 行動の決め方

- 各種に通常攻撃1つと、特技1〜2つを設定する。通常攻撃は物理・MP0・無属性。特技は物理攻撃、属性魔法、状態異常つき攻撃、自己強化、味方単体回復。
- 使用可能な行動から戦闘の保存乱数で抽選する。通常攻撃の重み60、攻撃特技30、強化20。使用不可の技を除外して再配分するため、固定確率や固定順序ではない。
- 回復役はHP55%以下の味方がいれば回復を優先する。対象は生存し、石化・回復禁止でない敵のうちHP割合が最も低い個体。最大HPの20%回復し、上限は最大HP。MP3。
- 自己強化は攻撃・魔力・防御・魔防のいずれかを25%上げる。既存の強化処理・持続カウントを使い、有効な同種強化がある間は選ばない。MP2、持続値3。
- 攻撃特技は使用後の次の1巡、回復は次の2巡、強化は次の3巡、再使用不可。通常攻撃は常時使用できる。待機解除の巡を敵個体に保存する。
- 沈黙は魔法、封印は物理特技、恐怖は全特技を禁止する。MP不足や禁止中は通常攻撃に戻る。睡眠・石化・混乱など、行動不能や強制行動の既存処理を優先する。
- 属性・追加状態異常は技ごとに適用する。通常攻撃へ特技の属性・状態異常を持ち越さない。耐性・回避・かばう・反撃・各ジョブの防御効果は既存戦闘処理を共有する。

## ボス・エリート・保存

- 石の巨人は「大地震」（物理・土）、嵐の大鷲は「嵐の翼」（魔法・風）。既存のボス周期を使用し、初期設定では3巡ごと、前巡に技名と全体攻撃を予告する。
- 全体攻撃はMP4・威力0.65。使用時に一度だけMPを払う。MP不足・封印／沈黙・恐怖などで発動できない場合は通常の行動選択に戻る。
- エリートは同名・同Lv・同じ種族・同じ技。同じ行動定義を使い、能力値とレアドロップ補正だけが異なる。
- 新しい敵生成時に技定義をコピーして戦闘へ保存する。途中セーブの敵定義、乱数、MP、再使用待機を維持する。技定義のない旧戦闘は既存AIを継続し、次の戦闘から新設定を使う。
- 対象外985種は既存AIのまま。39種の配置先・出現の重み・季節条件を設定済み。戦闘バランスの数値は最終確定ではない。
