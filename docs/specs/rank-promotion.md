# 冒険者ランク・昇級・施設解放（設計正本）

更新：2026-11-26。E〜Sのランク・ポイント・施設投資と、D〜Sの英語試験を実装済み。Dの納品素材は★2「崩れた砦」の砦の野盗が落とす「盗まれた鉄くず」2個。C以降の個別素材、神殿の職業解放、倉庫の容量制限、追加商品・レシピは未実装。

## 確定した方針

- ランクは E → E+ → D → D+ → C → C+ → B → B+ → A → A+ → S の11段階。名称は旧ランク表から選ぶ。
- すべての昇級で累積ギルドポイントとモンスター素材の納品を求める。Eは初期ランク。ギルドポイントは昇級時に消費しない。
- 依頼の★と種類で獲得ポイントを決める。冒険者ランクとの★差による減点・0点化は行わず、★1依頼もSまで常に加点する。
- `+`ランクには英語試験を設けない。D・C・B・A・Sへの昇級では単語30問と瞬間英作文15問を受け、両部門の合格を要する。英語教材の★難易度で受験を制限しない。
- 学びたい教材を選べるよう、英語教材の★とギルドランクを連動させない。試験は実際に取り組んだ履歴から出題する。
- 素材は受験資格の取得時に一度納品し、試験に不合格でも再納品は不要。分野別の合格記録は保持する。素材の入手先はそのダンジョンが公開された段階で入手可能であることを検証する。現行5ダンジョンだけで全ランクの素材を揃える必要はない。
- 昇級で施設への**投資上限**が開く。施設は自動強化しない。ダンジョンへの入場は冒険者ランクで制限せず、発見・踏破等の条件で制御する。
- 旧ランク表の `perk` 文章は新仕様に引き継がない。数値列 `quest_bonus`・`shop_discount` は維持・再設計を別途判断する。旧データの「★Nへ入れる」は新仕様ではない。

## 昇級試験とDの納品素材（実装済み）

昇級試験は訓練場の「試験の間」で受ける。全ランクで単語4択30問と瞬間英作文15問。先に異なる単語30件・英作文15件に取り組んでいることが出題の条件となるが、習得済み件数や教材の★は条件にしない。D・Cは最後に取り組んだ単語60件と英作文30件からそれぞれ抽選し、候補が少なければ学習履歴全体から必要数を出す。B・A・Sは学習履歴全体から抽選する。同日に学んだ項目は無作為に並べる。

| 昇級先 | 出題範囲 | 単語 | 英作文 | 合格率（各部門） |
| --- | --- | ---: | ---: | ---: |
| D・C | 直近60件・30件 | 30問 | 15問 | 80%（24問・12点） |
| B | 学習履歴全体 | 30問 | 15問 | 80%（24問・12点） |
| A | 学習履歴全体 | 30問 | 15問 | 90%（27問・13.5点） |
| S | 学習履歴全体 | 30問 | 15問 | 100%（30問・15点） |

英作文は解答表示後に自己判定する。できた=1点、だいたい=0.5点、できなかった=0点。自然な別表現も本人が「できた」と判定できる。単語と英作文は別々に合否を判定し、一度合格した部門の記録は保持する。失敗後は未合格部門だけ再受験できる。Sの「だいたい」は満点にならない。旧闘技場の最終戦をS試験の条件として流用しない。

Dへの受験には1,200Pと、★2「崩れた砦」の通常敵「砦の野盗」が落とす fort_bandit_mat（盗まれた鉄くず）2個が必要。崩れた砦の発見後に受験開始時に一度だけ納品し、不合格でも再納品は不要。E+など試験のないランクは条件達成時に納品して自動昇級する。C以降の個別素材は選定未済で、現状は公開済み・到達可能な対象★のモンスター素材1個を暫定条件とする。未公開★の素材は候補に含めない。

## ギルドポイントの報酬案（基本処理を実装）

討伐・採集依頼を基準とし、ボス依頼は3倍、賞金首依頼は5倍とする。対象の★は依頼先ダンジョンの★であり、冒険者ランクや教材の★ではない。格下依頼の減点は廃止し、★1の討伐・採集でも常に10Pを獲得する。期限付きの特別ボス依頼のポイントは通常の同★ボス依頼と同じとし、期限内ボーナスはゴールドのみに適用する。

### 約50時間を目指す試算の前提と結果

- 1遠征5分、平均1.3件の依頼を完了。完了した依頼の内訳を討伐40%・採集35%・ボス20%・賞金首5%と仮定する。1件当たりの平均獲得量は討伐・採集の基準点の1.6倍。
- 各昇級段階では上表の素材入手先と同じ★の依頼を主にこなすと仮定し、2万回の乱数試算を行う。実際は探索中の別の★の依頼も加点され、獲得ポイントの超過分は次段階へ持ち越す。
- EからSまで平均約489遠征・約640件の依頼で、**ポイント獲得に約40.7時間**。英語試験・素材集め・攻略準備など、ポイント獲得と並行しない作業に約9時間を見込むと総プレイ約50時間。追加時間は実測しておらず、総時間は目標値として扱う。
- 依頼を完了できる頻度が平均1遠征1.0件ならポイント獲得だけで約52.8時間、1.6件なら約33.1時間。掲示板や戦闘時間によって総所要時間は大きく変わる。
- 参考として、登録済みの60ダンジョンを各1回踏破し、各地で討伐・採集・ボス依頼を1件ずつ報告できても合計62,000P。Sの320,000Pには継続的な依頼達成が必要となる。

現在の掲示板は発見済みダンジョン全体から6件を抽選する。将来60か所すべてが候補になると、単純な均等抽選では約59%の掲示に★12依頼が1件もない。この試算のペースで上位依頼に取り組めるよう、**発見済みの★を選んで依頼を探す仕組み**をポイント実装と合わせて設計する。低★も選択可能にし、低★依頼のポイントを0にはしない。実プレイでは依頼の反復感も検証する。

現行の `data/quests.csv` と `game/js/town.js` は旧1・3・5Pと格下減点を使う。探索依頼など、別経路の旧1〜2Pも新しい規模に合わせて見直す。ランク表・得点計算・掲示板を同時に更新するまで、この節を実装済みの挙動として扱わない。

## 施設Lvの解放内容（現行処理を基にした設計目安）

**方向性：** ギルドランクは各施設への投資可能Lvを開く。施設はそれぞれゴールド等を投資してLvを1ずつ上げ、自動では成長しない。上のランク表にある投資可能Lv上限は仮値であり、実際に商品・レシピ・ジョブが増えるのは対応する施設への投資後。ダンジョンへの入場はランク・施設Lvで制限しない。

**施設の構成案：** 武器屋と防具屋は共通の「装備店Lv」を使用。武器・防具・装飾の制作と強化・付与は共通の「工房Lv」を使用。道具屋、調合、神殿、倉庫はそれぞれ独立して投資する。合計6系統。施設数・投資費用はバランス検証後に確定する。宿屋と闘技場には施設投資Lvを設けない。

## 実装時に決めること・移行上の注意

1. 素材の種類・個数・対象モンスターと入手経路、季節限定・低確率ドロップ・未公開場所による詰まりの回避。
2. C以降の個別納品素材と入手先。試験の問題数・出題範囲・合格率は本書の表を採用する。
3. ギルドポイントの獲得ペースと格下依頼の0点ルール。素材と英語試験がある前提で昇級できるか検証する。
4. 装備店・工房・調合・神殿・倉庫のLv別費用と移行、未収録の新商品・調合レシピ、ジョブのLv別割当を決める。施設だけで未訪問の★装備が先行販売されるかも検証する。
3. 上記ポイント報酬と累積値の実プレイ検証。格下依頼の0点・半減処理を廃止し、探索依頼などの報酬も調整する。発見済み★を選べる掲示板と、素材・試験を含む総プレイ時間を検証する。
4. 店売り装備の解放条件、施設の投資費用と必要素材、Lv5〜12の具体的な効果。ランクだけで未訪問の★装備が先行販売されるかも決める。
5. 旧R01〜R12+セーブのランク・ポイント・施設Lv・試験履歴・納品記録の移行。既存の取得物を無断で削除しない。移行規則が決まるまでCSVや昇級判定を置き換えない。
