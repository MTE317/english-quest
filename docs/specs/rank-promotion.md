# 冒険者ランク・昇級・施設解放（設計正本）

更新：2026-11-26。ランクの設計方針を記録する文書。現行の `data/adventurer_ranks.csv` と `game/js/town.js` は旧R01〜R12+方式であり、この表は**未実装**。実装まではゲーム画面の表示・判定も旧方式のまま。

## 確定した方針

- ランクは E → E+ → D → D+ → C → C+ → B → B+ → A → A+ → S の11段階。名称は旧ランク表から選ぶ。
- すべての昇級で累積ギルドポイントとモンスター素材の納品を求める。Eは初期ランク。
- `+`ランクには英語試験を設けない。D・C・B・A・Sへの昇級には単語と英作文の試験を求める。問題数、合格基準、習得数、出題範囲、Sの最終試験は別途設計する。
- 英語の項目の★難易度を冒険者ランクに紐づけて受験を制限しない。学びたい教材を選べるようにする。昇級試験の具体的な出題・定着確認は別途設計する。
- 素材は受験資格の取得時に一度納品し、試験に不合格でも再納品は不要。分野別の合格記録は保持する。素材の入手先はそのダンジョンが公開された段階で入手可能であることを検証する。現行5ダンジョンだけで全ランクの素材を揃える必要はない。
- 昇級で施設への**投資上限**が開く。施設は自動強化しない。ダンジョンへの入場は冒険者ランクで制限せず、発見・踏破等の条件で制御する。
- 旧ランク表の `perk` 文章は新仕様に引き継がない。数値列 `quest_bonus`・`shop_discount` は維持・再設計を別途判断する。旧データの「★Nへ入れる」は新仕様ではない。

## 施設投資とLv1〜12の仮案（2026-11-26）

**方向性：** ギルドランクは各施設への投資可能Lvを開く。施設はそれぞれゴールド等を投資してLvを1ずつ上げ、自動では成長しない。上のランク表にある投資可能Lv上限は仮値であり、実際に商品・レシピ・ジョブが増えるのは対応する施設への投資後。ダンジョンへの入場はランク・施設Lvで制限しない。

**施設の構成案：** 武器屋と防具屋は共通の「装備店Lv」を使用。武器・防具・装飾の制作と強化・付与は共通の「工房Lv」を使用。道具屋、調合、神殿、倉庫はそれぞれ独立して投資する。合計6系統。施設数・投資費用はバランス検証後に確定する。宿屋と闘技場には施設投資Lvを設けない。

- 道具屋Lvがバックパックの**拡張資格**を開く。拡張は別途、既存の `backpack.csv` のように費用・素材を払って実行する。道具屋への投資だけで枠数は自動増加しない。
- 調合Lvは道具屋Lvから分離する。現行 `alchemy_recipes.csv` ではLv3・5・8・9・11に新規レシピがなく、`items.csv` では道具屋Lv12の新商品がない。空段階を残さないため、追加または再配分を実装前に決める。

- 倉庫Lvは**倉庫内の装備枠**を増やす仮案。装備中は枠に数えず、素材は種類ごとに重ねて保管する。現行の倉庫は無制限なので、既存セーブの装備を削除せず、満杯時の遠征報酬・制作物・装備付替えの受け皿を設計してから上限を導入する。
- 宿屋の投資Lvは廃止し、通常宿泊と良い部屋を残す。現行Lv2〜12の宿泊補助効果をどこまで基本性能に残すかはバランス検証で決める。

**現行実装との差分：** 現在は工房が武器・防具・装飾の3施設、調合は道具屋Lvに依存し、装備店はギルドランクで品揃えを決める。神殿は素材奉納等の個別条件でジョブを解放し、倉庫は容量無制限、宿屋はLv制、闘技場の高階級は冒険者ランクに依存する。これらはこの施設案の実装完了を意味しない。

## 実装時に決めること・移行上の注意

1. 素材の種類・個数・対象モンスターと入手経路、季節限定・低確率ドロップ・未公開場所による詰まりの回避。
2. 各ランクの試験内容と、必要なら学習進捗条件。現行の20問＋10問、80%、固定習得数を確定値として流用しない。
3. ギルドポイントの獲得ペースと格下依頼の0点ルール。素材と英語試験がある前提で昇級できるか検証する。
4. 装備店・工房・調合・神殿・倉庫のLv別費用と移行、未収録の新商品・調合レシピ、ジョブのLv別割当を決める。施設だけで未訪問の★装備が先行販売されるかも検証する。
5. 旧R01〜R12+セーブのランク・ポイント・施設Lv・試験履歴・納品記録の移行。既存の取得物を無断で削除しない。移行規則が決まるまでCSVや昇級判定を置き換えない。
