# 承認済み追加3職（2026-11-23）

基本設計v1.0と50職候補に対する、Masatoさんが承認した最初の実装範囲。以下の数値は初回計測用として採用した値であり、計測後の再調整は再確認する。候補JSONの未承認部分を実装仕様に昇格させない。特に封技弓士の候補にある先付与・高命中は採用しない。

| ID / 名前 | 能力・装備適性 | 転職JP | 解放 |
|---|---|---:|---|
| infernalist / 炎術士 | 黒魔道士と同じ | 250 | lava_golem_rare:2 と lava_golem_mat:4 の奉納 |
| seal_archer / 封技弓士 | 狩人と同じ | 220 | 封印を使う対象敵を実際に討伐した、受注依頼の達成報告。例 q_bounty_07_2 / bounty_07_2 |
| neutralist / 無相術士 | 黒魔道士と同じ | 200 | paper_golem_rare:2 と paper_golem_mat:4 の奉納 |

元職の経験・マスターを解放条件にしない。既存の素材発見、安全帰還、倉庫素材消費、依頼対象・場所・報告、全滅巻戻しを利用する。儀式は鍵素材の発見後も職名を伏せ、報告解放職は事前に表示しない。既存のジョブID・セーブ形式を変えず、20職・209技能・6人編成・魔物1,024体となる。追加3職には新たなマスター報酬を設定しない。

各職は独立した通常技・パッシブ・奥義を1つずつ持つ。APは0 / 20 / 45、枠コストは2 / 2 / 4。通常技とパッシブは習得後に他職へ持ち出せる。奥義は現職専用・一戦一回で、既存の習得・装着・戦闘制限を用いる。未経験職のAP0技能を使えるようにはしない。

| 職 | 通常技 `_art` | パッシブ `_passive` | 奥義 `_ultimate` |
|---|---|---|---|
| infernalist | 炎獄輪：MP9、炎の全体直接魔法×1.0、火傷30% | 火傷への余熱：火傷中の対象への炎直接ダメージ+15% | 灰燼の火雨：MP20、炎の全体直接魔法×1.6、火傷40% |
| seal_archer | 封技の矢：MP7、武器依存単体×1.2、封印50% | 封印追撃：封印中の対象への弓の武器依存攻撃+15% | 静寂の一射：MP16、武器依存単体×2.0、封印65% |
| neutralist | 無相弾：MP6、無属性単体直接魔法×1.7 | 無相の節約：無属性の直接魔法技能のMP軽減へ10ポイント加算 | 白紙の星：MP18、無属性単体直接魔法×3.0 |

表のMPはデータの基礎値。既存のレベル係数、武器依存技能の武器倍率、MP_SAVEとの合算上限50%、最後の切上げを維持する。無相の節約は回復、遅延、通常攻撃、武器依存技能、固定ダメージには作用しない。属性未指定の直接魔法は、既存の戦闘処理と同じく無属性として扱う。

炎・封印の特効は既存の状態特効上限60%を共有し、継続ダメージには乗らない。状態付与は命中→ダメージ→状態判定の順で、初撃の付与を同じ初撃の特効に使わない。既存の耐性・免疫・ボス補正を維持し、必中にしない。

反撃の物理限定、魔法回避、魔力の余韻A案はこの差分では変更しない。PR #53の未マージ部分とは別管理。検証結果・再現手順・未実施範囲は [検証レポート](../../game/verification/three-jobs/README.md) を参照。
