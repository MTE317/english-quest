# 基本8職の独立習得と技能Lv（承認済み）

2026-11-24、基本8職の独立一覧・個別習得AP維持・17技のLv1〜3強化を承認。基準mainは `15293c366c90e8e9850bdb5f269d998541da7113`。

- 基本職だけ同職の前段技能の習得条件を撤廃。上位職の条件は維持する。表示は攻撃／回復・防御／妨害・支援／パッシブの独立一覧。
- Lv1の技能ID・効果・習得AP・装着枠・持出し・奥義制約は維持する。未経験職のAP0技能の扱いを拡張しない。
- 対象技能は所属職のAPを追加10でLv2、追加20でLv3にする。技能を習得していないキャラクターは強化できない。追加費用は正式データのeffect_json.levelsに記録。
- キャラごとの `skillLevels`（習得Lv）と `skillUseLevels`（使用Lv）を分ける。未指定はLv1。強化・装着・転職は使用Lvを勝手に上げない。使用Lvは町の装着画面で1〜習得Lvから選択する。戦闘中の選択変更は提供しない。
- 所属職APだけを使い、他の職や他のメンバーに強化を共有しない。他職へ持ち出した際も使用Lvを維持する。
- 最大技能Lvの取得はジョブマスター条件に加えない。従来の全技能習得と既得のmasteredJobsを維持する。
- セーブ外枠version 1、learned、loadout、AP、既存IDを維持し、上記の任意マップだけを追加する。通常ロードと遠征snapshotで同じ正規化を使い、旧セーブをLv1へ自然に補完する。実保存データのリセットや操作を要求しない。
- 通常戦・奥義の使用回数、状態付与率、回復の上限、反撃の物理限定、魔力の余韻A案を変えない。パッシブの強化や技能の統合・削除は行わない。

## 意図した変化と検証

例: 天裂きは従来の前提込み60 APから個別30 APで直接習得できる。早期奥義の取得速度を戻すための追加ゲートやAP再調整は承認に含まれない。比較結果に懸念があれば変更せず報告する。
