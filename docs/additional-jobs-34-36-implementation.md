# 追加職34〜36 実装記録

設計は [追加職31〜36の技能詳細](additional-jobs-31-36-skills-v1.md) に従う。商人・料理人・考古学者の各15技能、計45技能を神殿Lv9で解放する。

- 商人：補給札を戦闘内で管理し、道具の速配と緊急の気付けはバッグから品物を明示して各1個消費する。防護の残量と支援元も管理する。
- 料理人：味と取り分のある皿を一戦2回まで仕込み、本人の次の行動終了で完成させる。皿は戦闘終了時に消滅し、通常素材を食材にしない。
- 考古学者：鑑定印と遺物を戦闘内に保持し、属性・種族の情報は戦闘ログだけに表示する。転写は指定した味方の指定敵への次の攻撃に適用する。

補給札、料理、鑑定印、遺物は戦闘保存データに含め、戦闘不能と戦闘終了で破棄する。技能データは `node scripts/build-additional-job-skills.mjs` で再生成できる。
