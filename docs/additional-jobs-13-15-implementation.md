# 追加職13〜15 実装内容

銃士・海賊・魔法剣士の45技能（147段階）を、[設計書](additional-jobs-10-18-skills-v1.md)に沿ってゲームへ追加した。各職は最初から転職可能。習得には従来どおりAPが必要で、技能と奥義は他職へ継承できる。

| 職 | 固有の仕組み | 戦闘画面 |
| --- | --- | --- |
| 銃士 | 戦闘内の装填0〜3。特別弾はMPより先に弾数を検証し、行動単位で消費。通常の装弾だけが命中準備を生む。奥義は攻撃後に3へ補充。 | 装填数と命中・会心準備 |
| 海賊 | 通常武器技の主撃破で巡に一度余勢を獲得。次の通常武器技に威力とMP軽減を適用、または号令で消費。敵の一時攻撃強化だけを解除。 | 余勢と味方の強化 |
| 魔法剣士 | 炎・氷・雷の付与を保持し、通常攻撃と対応する技だけ属性を変更。WB技はSTRにMAGの35%を加算。防御は使用時の属性を保存。 | 属性と残り行動 |

弾数・付与・余勢・開幕の行動機会は戦闘状態に保存され、戦闘終了後は持ち越さない。対象や資源が足りない技はMP・奥義ゲージを使わない。設計正本は `docs/specs/additional-jobs-10-18-skills-v1.json`、実行効果は `scripts/additional-jobs-13-15-plans.mjs` から `data/skills.csv` に生成する。

検証は `node --test game/tests/*.test.js`。新職の転職・技能全段階・戦闘効果・資源不足・奥義属性選択を `game/tests/additional-jobs-13-15.test.js` で確認する。
