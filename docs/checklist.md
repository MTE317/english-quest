最終更新：2026-11-22。【済】はプルリクエスト#1で作ったもの。

## 3. バックパックと倉庫（2026-11-22 決定）

- ダンジョンで拾った装備と素材は、バックパックに自動で入る。装備1個で1枠、素材は1種類で1枠（99個まで）
- いっぱいになったら、拾ったものを見て「中の何かと入れ替える」か「あきらめる」を選ぶ
- 広さは12枠から50枠まで7段階。道具屋でお金と素材を払って広げる（`backpack.csv`）
- 道具（回復薬など）はバックパックとは別で、種類ごとに10個まで
- 町の倉庫は容量無限・無料。**倉庫代はなくし、月末に払うのはギルドの会費だけ**（会費を1.5倍にした）

## 3.5 詠唱とJP（2026-11-22 決定）

- 詠唱＝瞬間英作文。教材は単語とは別（`chants.csv`、文はこちらで用意する。今は仮の3文）
- 判定は自分で ○・△・×。JPは 10・6・3。1日の量（15・30・60問）を超えた分はJPなし
- JPはパーティ共有。転職のたびに、転職先の `change_jp`（基本80・中級200）を払う。最初のジョブはタダ
- 詠唱の記録は単語の学習記録とは別に保存し、全滅しても戻さない

## 4. そのほかの決めごと

- 自動保存は1つだけ、いつも上書き。戦闘が1つ終わるたびに保存し、ダンジョンの途中で閉じても再開できる。読み込み直して全滅をなかったことにはできない
- 全滅したら、ゲームの進み具合（お金・素材・拾った装備・経験値・AP・使った道具・日数）は入る前に戻す。学習記録（ルーンの状態・覚醒・正誤）は残す
- タイトル画面・設定は仮でよい。BGMや演出はあとで
- 図鑑（モンスター・装備）と称号は、一覧と「見た・手に入れた」の印だけ
- 遊び方の案内・実力診断・毎日ボーナスは作らない

## 5. ゲーム側からの質問への回答（`docs/requests.md` の 2026-11-21 分）

| 質問 | 回答 |
|---|---|
| srs.json に足してほしい項目 | 足した（`maximum_interval_days`・`learned_streak`・`learned_min_gap_days`・`familiar_streak`・`retry_gap`）。`fsrs_w` はゲーム側の FALLBACK（FSRS-5の初期値）をそのまま正とする |
| new_per_run の 10 | 普段は15語。かすれたルーンが増えるにつれて10語まで減らし、50を超えたら5語（`new_per_run_rule`） |
| 復習の日数 | 現実の日付で数える。日付の切り替わりは**午前4時**（`day_boundary_hour`） |
| 習得した単語を間違えたとき | 今のまま（学習中に戻し、連続正解数を0） |
| 間違えた単語の次の復習 | 今のまま（次の日） |
| 似た単語 | 今のつづりなどの方法でよい。`similar` 列は単語リストを作るときに入れる |
| 正誤の記録 | 1回ごとの記録はいらない。単語ごとの正解数・不正解数と、日ごとの合計（解いた数・正解数）を残す |
| BOM | CSV はBOMつき、JSON はBOMなし（README を直した） |
| `data/manifest.json` | 作った（data/ のファイル名の一覧） |

## 6. データ側からのお願い（2026-11-22）

- **テストが data/ の中身に頼らないようにしてほしい**。単語や数値はあとで入れ替わるため。今は次の2つが落ちる：
  - `quiz.test.js`「慣れたら、つづりの似た単語が選ばれやすい」：単語 `resign` を探している。単語を面接の語に入れ替えたので、もうない
  - `battle.test.js`「敵の能力値は balance.json の式」：383 を直接書いている。敵のHPの係数を 1.68→1.478 にしたので 337 になる
  - テスト用の小さなデータを `game/tests/` に持つか、期待値を data/ から計算する形にしてほしい
- 単語（`lexicon.csv`）を英語面接の90語に入れ替えた。ID の形（`lx_r{★}_{番号}`）と石の ID（`rs_1_001` など）は同じ。**端末に前の90語の学習記録が残っていたら、消してから遊ぶ**（同じ ID が別の単語になっている）
- 詠唱の文（`chants.csv`）にも、同じ単語の例文86文を「面接の魔導書」として入れた

## 8. クエストの掲示板の入れかえ（2026-11-22 決定）

- **月1回ではなく、ダンジョンから町に戻るたびに入れかえる**（クリアでも帰還でも）。受けているクエストは残し、受けていない枠だけ入れかえる。報告して空いた枠はその場で補充する
- 全滅したら入る前の状態に戻るので、掲示板も入る前のまま
- 設定は `balance.json` の `quest_board`。シミュレーションも遠征ごとにクエストを受ける前提なので、お金とランクの進み方は今の数値のまま
