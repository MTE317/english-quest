# AP（キャラ共通）

APはキャラごとに1つの残高を持ち、全ジョブのスキル習得・技能レベル強化・共通パッシブ習得に使う。仲間同士では共有しない。戦闘・訓練のAPはこの残高に加算する。転職しても残高は変わらない。

ジョブの経験履歴は visitedJobs に保存する。スキル一覧は経験したジョブを表示し、未経験ジョブの初期スキルを自動習得しない。スキルの装着・必要枠・奥義の現職制限は従来どおり。共通パッシブは習得後、全ジョブで常時有効。必要レベルは維持する。

共通パッシブの費用は data/common_tree.csv の ap_to_learn（通常10AP、旧2ptのノードは20AP）。旧 points 列はセーブ移行用に保持する。レベルアップによる共通ポイントの付与は廃止する。

## 既存セーブ

- ジョブ別の未使用APを合算する。AP残高0のジョブも経験履歴として保持する。
- 習得済みスキル・技能レベル・装着・共通パッシブは維持する。
- 未使用共通ポイント（Lv−1−習得済みノードの旧points合計、下限0）を1pt=10APで一度だけ換算する。換算率は balance.json の ap_system.legacy_common_point_ap。
- 訓練のジョブ別小数APを合算する。整数分はAPへ加算し、小数分はキャラ共通の繰越として保持する。
- apVersion=1 を記録し、再読込や以後のレベルアップでは旧ポイントを再付与しない。
- 遠征の入場時スナップショットも同じ規則で個別に移行し、全滅時の復元を維持する。
