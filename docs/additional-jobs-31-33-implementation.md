# 追加職31〜33 実装記録

設計は [追加職31〜36の技能詳細](additional-jobs-31-36-skills-v1.md) に従う。薬師・錬金術師・機工士の各15技能、計45技能を神殿Lv8で解放する。

- 薬師は実回復から薬効を得て、治療・予防・蘇生へ消費する。薬袋投与は所持する回復薬を明示選択して1個消費する。
- 錬金術師は炎・氷・雷の印を最大2枠に保存し、単独・混合放出と防護へ使う。実素材の投入は1戦1回で、所持する対象素材を1個消費する。
- 機工士は装置を1台設置し、燃料と耐久を攻撃・護衛・整備へ振り分ける。設置と整備はそれぞれ1戦2回まで。

専用資源は戦闘内だけで有効。問題待ちの保存・再開では選択、残回数、残期限、消費済みの在庫を保持する。既存のAP、技能セット、奥義EX、属性相性と状態異常耐性を利用する。技能データは `node scripts/build-additional-job-skills.mjs` で再生成できる。
