# 追加職19〜21 実装記録

設計の正本は [追加職19〜24](additional-jobs-19-24-skills-v1.md) と [全段階仕様](specs/additional-jobs-19-24-skills-v1.json)。死霊術師・陰陽師・巫女の各15技能、計45技能を技能CSVへ追加した。神殿Lv6で解放し、AP修得、固定装備cost、奥義専用枠、技能継承を既存職と共通に扱う。

| 職 | 戦闘での選択 |
| --- | --- |
| 死霊術師 | 魂灯の実ダメージから魂を得る。魂を攻撃・防護・亡霊の召喚へ配分し、亡霊には本人の行動で指示する。 |
| 陰陽師 | 光と闇の直接術を交互に当てて調和符を得る。結界・強化・単体術・複合術へ消費する。 |
| 巫女 | パーティで一つの神楽を切り替え、異常予防・継続回復・被害軽減を選ぶ。即時治療と予防札も使える。 |

魂、亡霊の残指示回数、調和符、直前の術属性、神楽、予防札は戦闘状態に保存する。問題待ちの再読込では期限や乱数を進めず、戦闘不能・戦闘終了で本人の一時状態を消す。技能が使えない場合は資源やMPを消費しない。

技能データは `node scripts/build-additional-job-skills.mjs` で再生成できる。専用テストは全45技能の全段階、召喚・消費・交替・複合属性・神楽の置換・治療順・保存再開を確認する。全職を含む長期編成バランスは別途検証する。
