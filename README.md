# English Quest

英単語とフレーズを覚えるためのファンタジーRPG。4択の英語の問題に答えると、パーティが行動する。ゴールはSランク冒険者になること。

## フォルダ

| フォルダ | 中身 |
|---|---|
| `game/` | ゲーム本体（GitHub Pages で公開する予定） |
| `data/` | ゲームの数値と単語（CSV / JSON）。ゲームとシミュレーターの両方が読む「正」 |
| `sim/` | 実ゲームのJSによるバランス計測と、旧Pythonモデル |
| `docs/` | 仕様、バランス調整の結果、36ビルドの設計・検証資料 |

Claude Code で作業するときの決まりは `CLAUDE.md` を参照。

## バランス調整とビルド

現在の職業・技能マスターは [50職の設計基準表](docs/jobs-baseline-v2.md) と [基本8職の技能設計](docs/basic-jobs-skills-v2.md) です。
基本8職の120技能（レベルなし28・最大Lv3 46・最大Lv5 46）、共通AP、最高修得Lvでの発動、継承可能な奥義専用1枠を実装しています。
追加36職と伝説6職は職業データを反映済みで、個別技能を実装するまでは転職先に表示しません。
新規開始は全員無装備・技能未修得です。倉庫の初級装備を手動で装備し、各キャラの初期AP30で技能を選んでください。
旧職業技能は費用相当APを一度だけ返還し、新しい技能を選び直します。詳細は [実装と検証](docs/jobs-master-implementation.md) を参照してください。

- [調整レポート](docs/balance-report.md)：冒険の長さ・難度・収支・新規開始・既存セーブへの対応と検証結果。
- [36ビルドの設計・検証資料](docs/build-catalog.md)：武器・技能・エンチャントの組み合わせと役割、苦手な相手を整理。
- [計測の再現方法](sim/README.md)：実ゲームの戦闘処理を使った比較条件とコマンド。

以前の36ビルド資料は旧技能マスターの記録です。現行の技能・数値を保証する資料としては使いません。
モンスター総数1,024、ルーンは教材、6人編成を維持します。現在の戦闘計測は基本8職の実ゲーム処理で行います。

現在のバランス確認にはNode.jsの計測を使います。実行例：

```sh
node game/verification/jobs-master/measure.mjs --samples=8
npm --prefix game test
```

## 旧Pythonモデル

以前の独立した戦闘・長期学習モデルを保存しています。新職業マスターの戦闘はJSで計測し、旧Pythonモデルでのキャラ生成は誤計算を防ぐため停止します。

```
cd sim
python3 base2.py 0.8        # 正答率80%で通しプレイ24回
python3 base2.py 0.5 0.65   # 正答率50%と65%
```

上級ジョブのデータはネタバレ防止のためこのリポジトリに入っていません。`secret/` がなくても動きます（上級ジョブなしで計算）。
