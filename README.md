# English Quest

英単語とフレーズを覚えるためのファンタジーRPG。4択の英語の問題に答えると、パーティが行動する。ゴールはSランク冒険者になること。

## フォルダ

| フォルダ | 中身 |
|---|---|
| `game/` | ゲーム本体（GitHub Pages で公開する予定） |
| `data/` | ゲームの数値と単語（CSV / JSON）。ゲームとシミュレーターの両方が読む「正」 |
| `sim/` | 実ゲームのJSによるバランス計測と、旧Pythonモデル |
| `docs/` | 仕様、バランス調整の結果、36ビルドの設計・検証資料 |

Claude Code で作業するときの決まりは `CLAUDE.md` を参照。

## バランス調整とビルド

- [調整レポート](docs/balance-report.md)：冒険の長さ・難度・収支・新規開始・既存セーブへの対応と検証結果。
- [36ビルドの設計・検証資料](docs/build-catalog.md)：武器・技能・エンチャントの組み合わせと役割、苦手な相手を整理。
- [計測の再現方法](sim/README.md)：実ゲームの戦闘処理を使った比較条件とコマンド。

第一弾は36ビルド。新しい共通効果7系統・技能8種・専用制作18件を追加し、公開14職・16武器を組み合わせます。ゲーム内にはビルドの手引きを置かず、技能詳細と装備効果の説明から自分で構成を考えられるようにしています。モンスター総数1,024、ルーンは教材という扱いを維持します。ゲーム本体のパーティー・冒険画面は6人編成に対応しました。過去の比較用ビルドと結果は4人のまま保持し、6人のバランス調整は別工程です。

現在のバランス確認にはNode.jsの計測を使います。実行例：

```sh
node sim/balance.mjs --stars 1,6,12 --runs 24 --workers 2
npm --prefix game test
```

## 旧Pythonモデル

以前の独立した戦闘・長期学習モデルを保存しています。今回のJSによる調整結果や実ゲームの到達年数としては扱いません。

```
cd sim
python3 base2.py 0.8        # 正答率80%で通しプレイ24回
python3 base2.py 0.5 0.65   # 正答率50%と65%
```

上級ジョブのデータはネタバレ防止のためこのリポジトリに入っていません。`secret/` がなくても動きます（上級ジョブなしで計算）。
