# English Quest

英単語とフレーズを学ぶファンタジーRPG。4択の英語問題に答えるとパーティーが行動する。Sランク冒険者を目指す。

## 現在の遊べる範囲

- 新規開始は6人編成。風渡りの原から森・洞窟・石切り場・湿原・砦、さらに風鳴りの峡谷へ段階的に進む。登録済みのダンジョンは60件で、中盤以降の大部分は先行版では非公開。
- 基本8職と追加36職の計44職・各15技能を実装。伝説6職は設計基準のみで技能未実装。
- 冒険者ランクはE〜Sの11段階。昇級ポイント、素材納品、D・C・B・A・Sの英語試験、5施設のLv1〜11投資を実装。C以降の個別納品素材は暫定条件。
- 町では武器・防具屋、工房、道具屋、調合所、神殿を投資で強化する。町の所持品に容量制限はなく、遠征中のバックパックには制限がある。
- 教材の正本は[基本版v1.0](data/learning/v1/README.md)。単語・熟語1,600件、瞬間英作文1,183件、チャンク215件。学習の★難度は冒険者ランクや入場条件と独立。

詳しい現行仕様は[仕様索引](docs/specs/README.md)。職業の全体像は[50職の設計基準](docs/jobs-baseline-v2.md)を参照。古い36ビルド資料や`docs/game-overview.md`、`docs/checklist.md`は履歴であり、現行の数値・解放条件の正本ではない。

## 構成と検証

| フォルダ | 内容 |
| --- | --- |
| `game/` | ブラウザで動くゲーム本体・Node.jsテスト |
| `data/` | CSV・JSONの数値、職業、教材の正本 |
| `sim/` | 実ゲームのJavaScriptによる計測と旧Pythonモデル |
| `docs/` | 現行仕様、設計案、検証記録 |

```sh
npm --prefix game test
node game/verification/jobs-master/measure.mjs --samples=8
```

データの読み込み・ゲーム処理を変えたときはテストと実ブラウザでの確認を行う。残る設計・検証項目は[未解決事項](docs/specs/OPEN-ISSUES.md)を参照。
